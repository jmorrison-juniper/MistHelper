# verifyTwoFactor

> verifyTwoFactor

## HTTP

`POST /api/v1/self/two_factor/verify`

## Description

Verify Two-factor (OTP)

To verify two-factor authentication by using a code generated by app (e.g. Google Authenticator, Authy). Upon successful verification, the `two_factor_passed` will be set to true if it hasn’t already been.


## Authentication

Requires API token authentication (`Authorization: Token {api_token}` header or `X-CSRFToken` cookie). See Mist API authentication documentation.

## Parameters

None.

## Request Body

Content-Type: `application/json`

```json
{
  "type": "object",
  "properties": {
    "two_factor": {
      "type": "string",
      "examples": [
        "123456"
      ]
    }
  },
  "required": [
    "two_factor"
  ],
  "description": "Request Body"
}
```

## Response

### 200

Response when 2FA verification is successful

## Usage Context

Use this endpoint to verify 2FA setup by submitting a TOTP code from the authenticator app. Common use cases:

- Completing 2FA enrollment after generating the secret via `GET /api/v1/self/two_factor/token`
- Confirming the authenticator app is correctly configured before enforcing 2FA

## Gotchas

- Must be called after generating a 2FA secret via `GET /api/v1/self/two_factor/token`
- The TOTP code is time-limited (typically 30 seconds) -- submit promptly
- After successful verification, 2FA is permanently enabled and required for all future logins
