# Licensing comparison

Open `/license-comparison` in the MistHelper web portal. The page uses the active Mist session to list organizations that the session can access.

Select one or more organizations, then select **Compare**. The page shows license use, site use, inventory, and request status. A failed request stays visible. It does not appear as zero use.

Use **Add manual organization** to add a local comparison row. Manual rows and purchased amounts stay in the current browser session. They are not sent to a database.

Select **Export CSV** to save the displayed comparison in the configured data directory. The export includes the source attribution. Read [the attribution and license terms](licensing-comparison-attribution.md).
