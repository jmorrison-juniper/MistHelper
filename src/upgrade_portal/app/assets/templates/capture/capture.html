{# capture/capture.html - the capture page of the upgrade capture portal. Why this file exists: One page covers the whole life of one capture. It starts the capture, it shows the progress, and it shows the result. A second page would need a second poll and a second set of test identifiers for the same six sections. Why the page holds no script: The content security policy is 'self' only. See src/upgrade_portal/app/ security.py. The policy blocks an inline script and blocks the style attribute. Every behavior of this page therefore lives in portal.js, and every color lives in a stylesheet. Why the links hold a literal path: contracts/http-api.md fixes every public path of this portal. The blueprint endpoint names are not fixed, and the route modules do not exist yet. A url_for call against an endpoint name would raise while this page renders, so every path follows the contract. url_for stays for a static asset. The contract with portal.js: portal.js reads data-capture-id and data-poll-seconds from the progress region. With a capture identifier it polls GET /api/captures//status every 30 seconds and paints the values below. The start button carries data-site-id, data-run-id, and data-role, which build the body of POST /api/sites//captures. Why the page polls instead of listening: Decision D3 of the plan fixes a 30-second poll. The portal sends no server-sent event, because the existing event bus caps at 10 subscribers. Variables a route may supply: site_id - the site the capture reads. The start button needs it. site_name - the site name for the heading. capture_id - the identifier of an existing capture. Empty before a start. status - the last known status. The shape matches the body of GET /api/captures//status exactly: state, percent, sections, counts, partial_reasons, verified, and message. portal.js paints the same fields from the poll, so the server render and the poll never disagree. stored_size_bytes - the stored size of the capture, in bytes. tier - 2 or 3. Defaults to 2, as contracts/http-api.md states. run_id - the run this capture belongs to. May be absent. role - `pre` or `post`. Defaults to `pre`. poll_interval_seconds - the poll period. Defaults to 30. page_title - the heading text and the tab text. theme, themes - see layout.html. #} {% extends 'layout.html' %} {% block title %}{{ page_title | default('Capture', true) }}{% endblock %} {% block heading %}
