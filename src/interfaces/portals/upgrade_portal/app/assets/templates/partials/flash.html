{# flash.html - the shared message region of the upgrade capture portal. Why this file exists: The portal reports a lock takeover, a partial capture, and a stop outcome from two places. The server reports one through a page reload. portal.js reports the other through a script, with no page change. The operator needs the same look for both, so both write into this one region. The contract with portal.js: getFlashRegion finds this element by the identifier flash-message. showFlash appends one child with the class "flash-item flash-". clearFlash sets the text content of the region to an empty string. Every server message below therefore uses that same child shape, and the region holds nothing else. A heading or a wrapper inside the region would disappear on the first clear. portal.css prepends "Note:", "Done:", "Caution:", and "Warning:" to the four levels. The level therefore reads without color, as WCAG 1.4.1 requires. #} {% set flash_levels = ['info', 'success', 'warning', 'danger'] %}
