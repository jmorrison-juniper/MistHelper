# Contract: Interactive-Test Telemetry

## Audience and transport

The interface is the local append-only JSONL telemetry generated by
`--testinteractive`. It is a local artifact only. Future implementation must
write it to a controlled path under `data/` and must not create remote records.

## Per-operation event

Every executed interactive-safe operation emits one terminal event with the
existing identifying fields plus these additive fields:

| Field | Type | Required | Contract |
|---|---|---:|---|
| `menu_option` | string | yes | Existing option identifier. |
| `operation_name` | string | yes | Existing description. |
| `duration_seconds` | number | yes | Existing rounded duration. |
| `test_mode` | string | yes | `interactive`. |
| `completion` | string | yes | `clean`, `logged_error`, `raised_exception`, or `prompt_cancelled`. |
| `site_context` | string | yes | `injected` or `unavailable`. |
| `error_log_count` | integer | yes | Count of scoped `ERROR`+ records; zero when none. |
| `input_termination` | string | yes | `none`, `eof`, or `interrupt`. |
| `error_type` | string | conditional | Required for `raised_exception`; may identify logged-error classification when no exception exists. |

Rules:

1. A normal handler return is `clean` only when no captured `ERROR` record,
   exception, EOF, or interrupt observation applies.
2. A captured `ERROR` record is `logged_error` even if the callable returned.
3. An escaped exception is `raised_exception`; it takes precedence over the
   other completion labels.
4. EOF and Ctrl+C observed through `InputUtils.safe_input` are
   `prompt_cancelled`, unless an exception or error observation has higher
   precedence.
5. `site_context=unavailable` is observable metadata, not a fabricated claim
   that the option ran against the resolved site.

## Summary event

The existing summary retains `pass_count`, `fail_count`, `skip_count`, and
`total_operations`. It additionally exposes:

| Field | Type | Contract |
|---|---|---|
| `clean_count` | integer | Explicit clean-operation count. |
| `logged_error_count` | integer | Operations classified as `logged_error`. |
| `raised_exception_count` | integer | Operations classified as `raised_exception`. |
| `prompt_cancelled_count` | integer | Operations that ended through observed cancellation. |
| `without_site_context_count` | integer | Operations invoked without injected `site_id`. |
| `requested_site_selector` | string/null | Requested selector, if one was supplied. |
| `actual_site_id` | string/null | Site used for a runnable suite. |
| `actual_site_name` | string/null | Name paired with `actual_site_id`. |

`status` is `fail` and process exit is non-zero when any operation is
`logged_error` or `raised_exception`. A supplied unresolved selector terminates
before operation execution and reports the requested selector prominently.

## Example

```json
{
  "event_type": "test_fail",
  "menu_option": "203",
  "operation_name": "WAN Client Events",
  "duration_seconds": 0.018,
  "test_mode": "interactive",
  "completion": "logged_error",
  "site_context": "injected",
  "error_log_count": 1,
  "input_termination": "none"
}
```
