# Phase 1 Quickstart: getOrgNacTag

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux in the Podman
  container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout.

There is deliberately no `.env` default for `nactag_id` -- see Research Task
5 in `research.md` for the rationale (avoids reading the wrong tag by
stale-default accident).

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it
with `chmod -R 777 data/` on Linux first to satisfy the non-root container
user).

- CSV: `data/org_<first-8-of-org-uuid>_nac_tag_<first-8-of-nactag-uuid>.csv`
- SQLite: `data/mist_data.db`, table `org_nac_tags` (upserted by
  primary key `id`)

The SQLite table is intentionally shared with the sibling `listOrgNacTags`
menu (44) so both bulk and single-record reads land in one queryable table.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class NacTagExportUtils:                                                            # existing (or newly-relocated) class -- no wrapper

    def export_org_nac_tag(self, org_id=None, nactag_id=None):                      # menu 89 entrypoint
        logging.info("Prompting for org_id for get NAC tag menu item")              # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_nac_tag:org_id",                                           # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 89", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for nactag_id")                                     # before-prompt action log
        nactag_id = nactag_id or safe_input(                                        # honor caller override else prompt user
            "NAC Tag ID (UUID): ",                                                  # human-readable prompt text
            context="org_nac_tag:nactag_id",                                        # SSH/container EOF context tag
        )
        if not is_valid_uuid(nactag_id):                                            # validate before any API call
            logging.warning("Invalid nactag_id %s -- aborting menu 89", nactag_id)  # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Fetching NAC tag %s for org %s",                              # before-API-call action log
                     nactag_id[:8], org_id[:8])                                     # log truncated IDs (never full UUIDs in prod chatter)
        response = mistapi.api.v1.orgs.nac_tags.getOrgNacTag(                       # actual SDK call
            self.apisession, org_id, nactag_id,                                     # positional args per mistapi convention
        )
        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug(                                                              # after-API-call summary log
            "NAC tag: name=%s type=%s match=%s",
            body.get("name"), body.get("type"), body.get("match"),
        )
        if not body:                                                                # empty payload edge case
            logging.warning("No NAC tag returned for %s -- nothing to write",       # log empty result (no traceback)
                            nactag_id[:8])
            return                                                                  # early return -- no export

        row = self._flatten_nac_tag(org_id, body)                                   # build one flat row (JSON-encode arrays)
        logging.info("Writing NAC tag record via DataExporter")                     # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [row],                                                                  # list-of-rows interface
            filename=f"org_{org_id[:8]}_nac_tag_{nactag_id[:8]}",                   # human-friendly stem
            api_function_name="getOrgNacTag",                                       # PK strategy lookup key
        )
```

Helper `_flatten_nac_tag` follows the same comment- and log-density rules,
stays under 25 lines, and lives on the same `NacTagExportUtils` class -- no
standalone wrapper functions. It serializes the polymorphic array/object
fields (`values`, `egress_vlan_names`, `radius_attrs`, `radius_vendor_attrs`,
`gbp_tag`) to JSON strings for storage in the `_json`-suffixed columns
documented in `data-model.md`.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 89 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 89 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the org and NAC tag
configured in `.env`.
