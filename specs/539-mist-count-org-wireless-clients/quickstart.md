# Phase 1 Quickstart: countOrgWirelessClients

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` / `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell inside the Podman container).
- Python 3.13 or newer on `PATH`.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ and `python-dotenv` installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; on Linux create it with
`chmod -R 777 data/` once to satisfy the non-root container user).

- Envelope CSV: `data/org_<first-8-of-org-uuid>_wireless_clients_count_envelope.csv`
- Results CSV:  `data/org_<first-8-of-org-uuid>_wireless_clients_count_results.csv`
- SQLite: `data/mist_data.db`, tables `org_wireless_clients_count_envelope` and
  `org_wireless_clients_count_results`.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents the
expected shape so that inline-comment and action-logging coverage can be reviewed before
the code is written. Every executable line carries a `#` comment (Constitution VI), and
every meaningful action is bracketed by `logging.info()` / `logging.debug()` calls
(Constitution VII).

```python
class ClientSearchUtils:                                                             # existing class, no new wrapper

    def export_org_wireless_clients_count(                                           # menu 96 entrypoint
        self, org_id=None, distinct_field=None, duration="1d", limit=100,
    ):
        logging.info("Prompting for org_id for wireless client count menu item")     # before-prompt action log
        org_id = org_id or safe_input(                                               # honor caller override else prompt user
            "Org ID (UUID): ",                                                       # human-readable prompt text
            context="count_org_wireless_clients:org_id",                             # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                               # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                                # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 96", org_id)         # log validation failure (no traceback)
            return                                                                   # early return per safety-first principle

        logging.info("Prompting for distinct field")                                 # before-prompt action log
        distinct_field = distinct_field if distinct_field is not None else safe_input(  # honor caller else prompt
            "Distinct field [ssid|hostname|os|device|model|ap|vlan|ip|mac|(blank)]: ",  # whitelisted enum prompt
            context="count_org_wireless_clients:distinct",                           # EOF context tag
            default="",                                                              # blank means no grouping
        )
        allowed = {"", "ssid", "hostname", "os", "device", "model", "ap", "vlan", "ip", "mac"}  # enum
        if distinct_field not in allowed:                                            # reject unknown grouping attribute
            logging.warning("Unknown distinct field %s -- aborting menu 96", distinct_field)  # log + abort
            return                                                                   # early return

        logging.info("Prompting for duration window")                                # before-prompt action log
        duration = duration or safe_input(                                           # honor caller else prompt
            "Duration window (e.g. 1d, 7d, 2w) [1d]: ",                              # API matches our default of 1d
            context="count_org_wireless_clients:duration",                           # EOF context tag
            default="1d",                                                            # match Mist API default
        )

        logging.info("Prompting for result limit")                                   # before-prompt action log
        limit = self._prompt_int_limit(limit)                                        # parsing + re-prompt helper (<25 lines)

        logging.info(                                                                # before-API-call action log
            "Fetching wireless client count for org %s distinct=%s duration=%s limit=%s",
            org_id, distinct_field or "(none)", duration, limit,
        )
        response = mistapi.api.v1.orgs.clients.count.countOrgWirelessClients(        # actual SDK call
            self.apisession, org_id,
            distinct=distinct_field or None,                                         # omit query param when blank
            duration=duration, limit=limit,                                          # rest of supported defaults
        )
        body = response.data or {}                                                   # normalize None to empty dict
        results = body.get("results") or []                                          # safe default if API omits array
        logging.debug(                                                               # after-API-call summary log
            "Count response: total=%s buckets=%s distinct=%s start=%s end=%s",
            body.get("total"), len(results), body.get("distinct"),
            body.get("start"), body.get("end"),
        )

        logging.info("Flattening envelope payload for org %s", org_id)               # before-flatten action log
        envelope_row = self._flatten_wireless_count_envelope(org_id, body, results)  # one envelope dict
        logging.debug("Flattened 1 envelope row")                                    # after-flatten count log

        logging.info("Flattening %d result rows", len(results))                      # before-flatten action log
        result_rows = self._flatten_wireless_count_results(org_id, body, results)    # list of bucket dicts
        logging.debug("Flattened %d result rows", len(result_rows))                  # after-flatten count log

        logging.info("Writing wireless client count envelope via DataExporter")     # before-write action log
        DataExporter.write_with_format_selection(                                    # multi-backend write
            [envelope_row],                                                          # list-of-rows interface
            filename=f"org_{org_id[:8]}_wireless_clients_count_envelope",            # human-friendly stem
            api_function_name="countOrgWirelessClients",                             # PK strategy lookup key
        )

        logging.info("Writing wireless client count results via DataExporter")      # before-write action log
        DataExporter.write_with_format_selection(                                    # second multi-backend write
            result_rows,                                                             # may be empty list
            filename=f"org_{org_id[:8]}_wireless_clients_count_results",             # human-friendly stem
            api_function_name="countOrgWirelessClientsResults",                      # MistHelper-internal sub-table key
        )
```

The flatten helpers (`_flatten_wireless_count_envelope`,
`_flatten_wireless_count_results`) and the int-limit prompt helper
(`_prompt_int_limit`) live on the same `ClientSearchUtils` class, each stay under 25
lines, and follow the same comment / logging density rules. No standalone wrapper
functions are introduced.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 96 included)
```

The `--test` sweep automatically skips heavy / destructive operations (14, 18, 63-65,
90-100). Proposed menu 96 sits just outside the skip range and inside the standard
sweep, so a green run confirms the new item works end to end against the org configured
in `.env`.
