# Phase 1 Quickstart: countSiteOspfStats

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new menu
item on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_SITE_ID=<your-default-site-uuid>   # optional default for the site_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user, per the
project README).

- CSV: `data/site_<first-8-of-site-uuid>_ospf_peers_count_<distinct_attribute>.csv`
  (for example `data/site_0a1b2c3d_ospf_peers_count_neighbor.csv`)
- SQLite: `data/mist_data.db`, table `site_ospf_peers_count`
- ArangoDB / Redis (when enabled): collection / namespace
  `site_ospf_peers_count` keyed by the composite PK tuple defined in `data-model.md`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before the code is written. Every executable line carries a `#` comment (Constitution
VI), and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class SiteStatsExportUtils:                                                           # existing class -- no new wrapper

    def export_site_ospf_peers_count(                                                 # menu 89 entrypoint
        self,
        site_id=None,                                                                 # path param; may be supplied by caller
        distinct=None,                                                                # group-by attribute; None -> server default
        time_window=None,                                                             # (start, end) tuple; None -> prompt
    ):
        logging.info("Prompting for site_id for OSPF peer count menu item")           # before-prompt action log
        site_id = site_id or safe_input(                                              # honor caller override else prompt
            "Site ID (UUID): ",                                                       # human-readable prompt
            context="site_ospf_peers_count:site_id",                                  # EOF context tag for SSH/container
            default=os.environ.get("MIST_SITE_ID", ""),                               # fall back to .env default
        )
        if not is_valid_uuid(site_id):                                                # validate before any API call
            logging.warning("Invalid site_id %s -- aborting menu 89", site_id)        # log validation failure (no traceback)
            return                                                                    # early return per safety-first principle

        distinct = distinct if distinct is not None else safe_input(                  # ask for distinct attribute
            "Distinct attribute (neighbor | state | area | vrf_name | mac) [default: server-default]: ",
            context="site_ospf_peers_count:distinct",                                 # EOF context tag
            default="",                                                               # empty -> omit query param
        ).strip().lower()                                                             # normalize for the SDK call

        window_start, window_end = time_window or (                                   # ask only when caller did not supply
            safe_input("Window start (epoch seconds or relative, e.g. -1d): ",
                       context="site_ospf_peers_count:start", default="-1d"),
            safe_input("Window end (epoch seconds or relative, e.g. now): ",
                       context="site_ospf_peers_count:end", default="now"),
        )
        window_start = resolve_to_epoch(window_start)                                 # client-side resolution for stable PK
        window_end = resolve_to_epoch(window_end)                                     # client-side resolution for stable PK

        org_id = self.apisession.get_active_org_id()                                  # injected into every row at flatten time
        all_rows, page = [], 0                                                        # accumulator and counter for pagination loop
        search_after = None                                                           # initial cursor (None -> first page)
        while True:                                                                   # cursor-paginated fetch
            page += 1                                                                 # human-readable page index for logs
            logging.info(                                                             # before-API-call action log per page
                "Fetching OSPF peer count for site %s distinct=%s page=%d",
                site_id, distinct or "default", page,
            )
            response = mistapi.api.v1.sites.stats.ospf_peers.count.countSiteOspfStats(  # SDK call
                self.apisession, site_id,
                distinct=distinct or None,                                            # omit when user left it blank
                start=window_start, end=window_end,                                   # resolved epoch seconds
                search_after=search_after,                                            # opaque cursor from prior page
            )
            body = response.data or {}                                                # normalize None to empty dict
            buckets = body.get("results") or []                                       # safe access to results array
            logging.debug(                                                            # after-API-call summary log
                "Received %d buckets on page %d (total=%s)",
                len(buckets), page, body.get("total"),
            )
            all_rows.extend(                                                          # flatten this page's buckets
                self._flatten_ospf_count_bucket(org_id, site_id, distinct, window_start, window_end, body, bucket)
                for bucket in buckets
            )
            search_after = _extract_search_after(response)                            # parse next cursor or None
            if not search_after:                                                      # no more pages
                break                                                                 # exit pagination loop cleanly

        logging.debug("Flattened %d rows total across %d page(s)", len(all_rows), page)  # after-flatten log
        logging.info("Writing site OSPF peer count via DataExporter")                 # before-export action log
        DataExporter.write_with_format_selection(                                     # multi-backend write
            all_rows,                                                                 # may be empty list when no buckets
            filename=f"site_{site_id[:8]}_ospf_peers_count_{distinct or 'default'}", # human-friendly stem
            api_function_name="countSiteOspfStats",                                   # PK strategy lookup key
        )
```

Helpers `_flatten_ospf_count_bucket` and `_extract_search_after` follow the same
comment- and log-density rules, stay under 25 lines each, and live on the same
`SiteStatsExportUtils` class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 89 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 89 sits inside the standard sweep range, so a green run confirms the
new item works end to end against the site configured in `.env`.
