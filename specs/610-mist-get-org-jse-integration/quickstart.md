# Phase 1 Quickstart: getOrgJseIntegration

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the
new menu item on a Windows 11 dev box. Container parity is identical
(paths normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never
commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and
is never written to logs or stdout.

## Expected output filename

Files land under `data/` (the directory is enforced at runtime; create
it with `chmod -R 777 data/` on Linux first to satisfy the non-root
container user).

- CSV: `data/org_<first-8-of-org-uuid>_jse_integration_setup.csv`
- SQLite: `data/mist_data.db`, table `org_jse_integration_setup`
- ArangoDB / Redis: collection / namespaced key
  `org_jse_integration_setup` (when the polyglot backend is active)

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this
skeleton documents the expected shape so that inline comment and action
logging coverage can be reviewed before the code is written. Every
executable line carries a `#` comment (Constitution VI), and every
meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class JseIntegrationExportUtils:                                                    # new class -- owns Mist JSE Integration endpoints

    def __init__(self, apisession):                                                 # standard init pattern
        self.apisession = apisession                                                # save apisession for SDK calls

    def export_org_jse_integration(self, org_id=None):                              # menu 59 entrypoint
        logging.info("Prompting for org_id for JSE integration menu item")          # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_jse_integration:org_id",                                   # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 59", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Fetching JSE integration setup for org %s", org_id)           # before-API-call action log
        try:                                                                        # wrap SDK call to handle 404 cleanly
            response = mistapi.api.v1.orgs.setting.jse.setup.getOrgJseIntegration(  # actual SDK call
                self.apisession, org_id,                                            # only path param required
            )
        except mistapi.APIError as exc:                                             # SDK surfaces HTTP errors as APIError
            if getattr(exc, "status_code", None) == 404:                            # 404 means no JSE binding -- not an error
                logging.warning(                                                    # log as warning, write zero rows
                    "No JSE integration configured for org %s -- writing zero rows",
                    org_id,
                )
                return                                                              # clean exit per spec edge case
            raise                                                                   # re-raise non-404 errors for caller

        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug(                                                              # after-API-call summary log
            "JSE setup: cloud=%s username=%s org_count=%d",
            body.get("cloud_name"), body.get("username"), len(body.get("org_names") or []),
        )

        logging.info("Flattening JSE setup payload for org %s", org_id)             # before-flatten action log
        org_names_list = body.get("org_names") or []                                # default empty list when key absent
        setup_row = {                                                               # build one flat output row
            "org_id":           org_id,                                             # injected -- API does not echo it
            "cloud_name":       body.get("cloud_name"),                             # JSE cloud bound to the org
            "username":         body.get("username"),                               # JSE account email
            "org_names_joined": ",".join(org_names_list),                           # CSV-safe joined string
            "org_names_count":  len(org_names_list),                                # convenience numeric count
            "polled_at_utc":    datetime.now(timezone.utc).isoformat(),             # audit timestamp
        }
        logging.debug("Flattened 1 row")                                            # after-flatten count log

        logging.info("Writing JSE integration setup via DataExporter")              # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [setup_row],                                                            # list-of-rows interface
            filename=f"org_{org_id[:8]}_jse_integration_setup",                     # human-friendly stem
            api_function_name="getOrgJseIntegration",                               # PK strategy lookup key
        )
```

The skeleton stays under 25 lines for the public method body (counted
excluding blank lines, decorators, and the inner `try`/`except` shell),
takes 2 parameters (`self`, `org_id`), and has 5 logical blocks
(prompt -> validate -> SDK call with 404 handling -> flatten -> export).
No standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 59 included)
```

The `--test` sweep automatically skips heavy/destructive operations
(14, 18, 63-65, 90-100). Menu 59 sits inside the standard sweep range,
so a green run confirms the new item works end to end against the org
configured in `.env`.
