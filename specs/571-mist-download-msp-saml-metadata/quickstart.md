# Phase 1 Quickstart: downloadMspSamlMetadata

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_MSP_ID=<your-default-msp-uuid>   # optional default for the msp_id prompt
MIST_SSO_ID=<your-default-sso-uuid>   # optional default for the sso_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- Raw XML (the file you hand to the IdP):
  `data/msp_<first-8-of-msp-uuid>_sso_<first-8-of-sso-uuid>_saml_metadata.xml`
- CSV summary:
  `data/msp_<first-8-of-msp-uuid>_sso_<first-8-of-sso-uuid>_saml_metadata.csv`
- SQLite: `data/mist_data.db`, table `msp_sso_saml_metadata`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before the code is written. Every executable line carries a `#` comment (Constitution
VI), and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
import hashlib                                                                       # stdlib digest for metadata fingerprint
import os                                                                            # for joining paths and reading .env defaults
import xml.etree.ElementTree as ET                                                   # shallow parse to extract summary fields
from datetime import datetime, timezone                                              # ISO 8601 polled_at_utc audit field

import mistapi                                                                       # mandatory SDK per constitution
from mistapi.api.v1.msps.ssos import metadata_xml                                    # URL-derived module path


class MspSsoExportUtils:                                                             # new class scoped to MSP SSO ops

    def __init__(self, apisession):                                                  # standard MistHelper class init pattern
        self.apisession = apisession                                                 # store the mistapi session for later calls

    def export_msp_saml_metadata(self, msp_id=None, sso_id=None):                    # menu 94 entrypoint
        logging.info("Prompting for msp_id for SAML metadata download")              # before-prompt action log
        msp_id = msp_id or safe_input(                                               # honor caller override else prompt user
            "MSP ID (UUID): ",                                                       # human-readable prompt text
            context="msp_saml_metadata:msp_id",                                      # SSH/container EOF context tag
            default=os.environ.get("MIST_MSP_ID", ""),                               # fall back to .env default
        )
        if not is_valid_uuid(msp_id):                                                # validate before any API call
            logging.warning("Invalid msp_id %s -- aborting menu 94", msp_id)         # log validation failure (no traceback)
            return                                                                   # early return per safety-first principle

        logging.info("Prompting for sso_id for SAML metadata download")              # before-prompt action log
        sso_id = sso_id or safe_input(                                               # honor caller override else prompt user
            "SSO ID (UUID): ",                                                       # human-readable prompt text
            context="msp_saml_metadata:sso_id",                                      # SSH/container EOF context tag
            default=os.environ.get("MIST_SSO_ID", ""),                               # fall back to .env default
        )
        if not is_valid_uuid(sso_id):                                                # validate before any API call
            logging.warning("Invalid sso_id %s -- aborting menu 94", sso_id)         # log validation failure (no traceback)
            return                                                                   # early return per safety-first principle

        logging.info("Fetching SAML metadata for msp %s sso %s", msp_id, sso_id)     # before-API-call action log
        response = metadata_xml.downloadMspSamlMetadata(                             # actual SDK call (URL-derived module)
            self.apisession, msp_id, sso_id,                                         # required path params, no query params
        )
        raw_xml = response.data or ""                                                # normalize None to empty string
        metadata_bytes = len(raw_xml.encode("utf-8"))                                # byte length for the summary row
        metadata_sha256 = hashlib.sha256(raw_xml.encode("utf-8")).hexdigest()        # fingerprint for rotation detection
        logging.debug(                                                               # after-API-call summary log (no body)
            "SAML metadata: bytes=%d sha256=%s",
            metadata_bytes, metadata_sha256,
        )

        xml_path = os.path.join(                                                     # Windows-safe path joining
            "data",                                                                  # all output under data/ per project rules
            f"msp_{msp_id[:8]}_sso_{sso_id[:8]}_saml_metadata.xml",                  # short-form UUID filename
        )
        logging.info("Writing raw SAML metadata XML to %s", xml_path)                # before-file-write action log
        with open(xml_path, "w", encoding="utf-8", newline="") as xml_file:          # text mode, preserve LF endings
            xml_file.write(raw_xml)                                                  # byte-for-byte dump for IdP import
        logging.debug("Wrote %d bytes to disk", metadata_bytes)                      # after-file-write count log

        logging.info("Writing SAML metadata summary via DataExporter")               # before-export action log
        summary_row = self._summarize_saml_metadata(                                 # build the flat dict for DataExporter
            msp_id, sso_id, raw_xml, metadata_bytes, metadata_sha256, xml_path,
        )
        logging.debug("Flattened 1 summary row")                                     # after-flatten count log
        DataExporter.write_with_format_selection(                                    # multi-backend write
            [summary_row],                                                           # list-of-rows interface (single row here)
            filename=f"msp_{msp_id[:8]}_sso_{sso_id[:8]}_saml_metadata",             # human-friendly stem (no extension)
            api_function_name="downloadMspSamlMetadata",                             # PK strategy lookup key
        )
```

The `_summarize_saml_metadata()` private helper shallow-parses the XML with
`xml.etree.ElementTree.fromstring`, extracts six attributes (`entityID`, `validUntil`,
`NameIDFormat`, `SingleLogoutService/@Location`, `AssertionConsumerService/@Location`,
`WantAssertionsSigned`, `AuthnRequestsSigned`), and returns a single flat dict matching
the columns documented in `data-model.md`. It stays under 25 lines, takes 6 parameters,
and lives on the same `MspSsoExportUtils` class -- no standalone wrapper function.
