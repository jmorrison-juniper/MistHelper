# Phase 1 Quickstart: getOrgIdpProfile

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>            # optional default for prompt 1
MIST_IDP_PROFILE_ID=<your-default-profile-uuid> # optional default for prompt 2
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout. The new `MIST_IDP_PROFILE_ID` variable is
strictly optional -- it exists so `python MistHelper.py --menu 96` can run
non-interactively in `--test` mode. Add it to `deploy/.env.example` in the
same PR as the implementation.

To discover a real profile UUID for testing:

```powershell
python MistHelper.py --menu <num for listOrgIdpProfiles>
# inspect data/<org>_listOrgIdpProfiles.csv and pick any row's id column
```

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it
with `chmod -R 777 data/` on Linux first to satisfy the non-root container
user).

- Summary CSV: `data/org_<first-8-of-org-uuid>_idp_profile_<first-8-of-idp-uuid>_summary.csv`
- Overwrites CSV: `data/org_<first-8-of-org-uuid>_idp_profile_<first-8-of-idp-uuid>_overwrites.csv`
  (always emitted; will contain zero data rows when the profile has no
  overwrite rules, header row only)
- SQLite: `data/mist_data.db`, tables `org_idp_profile_summary` and
  `org_idp_profile_overwrites`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class OrgClientSecurityExporter:                                                # existing class, no new wrapper

    @staticmethod
    def export_org_idp_profile(org_id=None, idpprofile_id=None):                # menu 96 entrypoint
        logging.info("Prompting for org_id for IDP profile menu item")          # before-prompt action log
        org_id = org_id or safe_input(                                          # honor caller override else prompt user
            "Org ID (UUID): ",                                                  # human-readable prompt text
            context="org_idp_profile:org_id",                                   # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                          # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                           # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 96", org_id)    # log validation failure (no traceback)
            return                                                              # early return per safety-first principle

        logging.info("Prompting for idpprofile_id")                             # before-prompt action log
        idpprofile_id = idpprofile_id or safe_input(                            # caller override else prompt user
            "IDP Profile ID (UUID): ",                                          # human-readable prompt text
            context="org_idp_profile:idpprofile_id",                            # EOF context tag
            default=os.environ.get("MIST_IDP_PROFILE_ID", ""),                  # optional .env default
        )
        if not is_valid_uuid(idpprofile_id):                                    # validate before any API call
            logging.warning("Invalid idpprofile_id %s -- aborting", idpprofile_id)  # log validation failure
            return                                                              # early return per safety-first principle

        logging.info("Fetching IDP profile %s for org %s",                      # before-API-call action log
                     idpprofile_id[:8], org_id[:8])                             # log short UUIDs only (no secrets)
        response = mistapi.api.v1.orgs.idpprofiles.getOrgIdpProfile(            # actual SDK call
            APISESSION, org_id, idpprofile_id,                                  # required path params
        )
        body = response.data or {}                                              # normalize None to empty dict
        overwrites = body.get("overwrites") or []                               # default to empty list if absent
        logging.debug(                                                          # after-API-call summary log
            "IDP profile: name=%s base_profile=%s overwrites=%d",
            body.get("name"), body.get("base_profile"), len(overwrites),
        )

        logging.info("Flattening IDP profile summary")                          # before-flatten action log
        summary_row = OrgClientSecurityExporter._flatten_idp_summary(body)      # build one summary dict
        logging.debug("Flattened 1 summary row")                                # after-flatten count log

        logging.info("Flattening %d overwrite rules", len(overwrites))          # before-flatten action log
        overwrite_rows = OrgClientSecurityExporter._flatten_idp_overwrites(     # build N overwrite dicts
            body.get("id"), overwrites,                                         # parent UUID + array
        )
        logging.debug("Flattened %d overwrite rows", len(overwrite_rows))       # after-flatten count log

        logging.info("Writing IDP profile summary via DataExporter")            # before-export action log
        DataExporter.write_with_format_selection(                               # multi-backend write
            [summary_row],                                                      # list-of-rows interface
            filename=f"org_{org_id[:8]}_idp_profile_{idpprofile_id[:8]}_summary",  # human-friendly stem
            api_function_name="getOrgIdpProfile",                               # PK strategy lookup key
        )

        logging.info("Writing IDP profile overwrites via DataExporter")         # before-export action log
        DataExporter.write_with_format_selection(                               # second multi-backend write
            overwrite_rows,                                                     # may be empty list
            filename=f"org_{org_id[:8]}_idp_profile_{idpprofile_id[:8]}_overwrites",  # human-friendly stem
            api_function_name="getOrgIdpProfileOverwrites",                     # MistHelper-internal sub-table key
        )
```

Helpers `_flatten_idp_summary` and `_flatten_idp_overwrites` follow the same
comment- and log-density rules, stay under 25 lines, and live on the same
`OrgClientSecurityExporter` class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 96 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 96 sits at the top of the Interactive Safe band; the
skip list starts at 97, so the new item is exercised on every test run.
For menu 96 to pass non-interactively, both `MIST_ORG_ID` and
`MIST_IDP_PROFILE_ID` must be set in `.env` -- if either is missing the
method logs a warning and returns 0 without writing files, which the test
harness accepts as a clean skip.
