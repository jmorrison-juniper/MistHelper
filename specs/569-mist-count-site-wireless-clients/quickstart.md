# Phase 1 Quickstart: countSiteWirelessClients

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_SITE_ID=<your-default-site-uuid>   # optional default for the site_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- Summary CSV:
  `data/site_<first-8-of-site-uuid>_wireless_client_count_summary.csv`
- Results CSV:
  `data/site_<first-8-of-site-uuid>_wireless_client_count_results.csv`
- SQLite: `data/mist_data.db`, tables `site_wireless_client_count_summary` and
  `site_wireless_client_count_results`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before the code is written. Every executable line carries a `#` comment (Constitution
VI), and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class SiteClientExportUtils:                                                        # existing class, no new wrapper

    DISTINCT_ALLOWED = (                                                            # documented Mist allow-list
        "ssid", "ap", "ip", "vlan", "hostname", "os", "model", "device",
    )

    def export_site_wireless_client_count(                                          # menu 89 entrypoint
        self, site_id=None, distinct=None, start=None, end=None,
    ):
        logging.info("Prompting for site_id for wireless client count menu item")   # before-prompt action log
        site_id = site_id or safe_input(                                            # honor caller override else prompt user
            "Site ID (UUID): ",                                                     # human-readable prompt text
            context="site_wireless_client_count:site_id",                           # SSH/container EOF context tag
            default=os.environ.get("MIST_SITE_ID", ""),                             # fall back to .env default
        )
        if not is_valid_uuid(site_id):                                              # validate before any API call
            logging.warning("Invalid site_id %s -- aborting menu 89", site_id)      # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for distinct field")                                # before-prompt action log
        distinct = (distinct or safe_input(                                         # honor caller override else prompt
            "Group-by field [ssid|ap|ip|vlan|hostname|os|model|device] "            # human-readable prompt text
            "(default: device): ",
            context="site_wireless_client_count:distinct",                          # EOF context tag
            default="device",                                                       # explicit default for non-interactive runs
        )).strip().lower() or "device"                                              # normalize empty input to default
        if distinct not in self.DISTINCT_ALLOWED:                                   # validate against allow-list
            logging.warning(                                                        # log validation failure (no traceback)
                "Invalid distinct field %s -- allowed: %s",
                distinct, ",".join(self.DISTINCT_ALLOWED),
            )
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for time window start")                             # before-prompt action log
        start = start if start is not None else safe_input(                         # honor caller override else prompt
            "Start (epoch or relative e.g. -1d, blank for default): ",              # human-readable prompt text
            context="site_wireless_client_count:start",                             # EOF context tag
            default="",                                                             # blank means omit parameter
        )
        logging.info("Prompting for time window end")                               # before-prompt action log
        end = end if end is not None else safe_input(                               # honor caller override else prompt
            "End (epoch or relative e.g. now, blank for default): ",                # human-readable prompt text
            context="site_wireless_client_count:end",                               # EOF context tag
            default="",                                                             # blank means omit parameter
        )

        logging.info(                                                               # before-API-call action log
            "Counting wireless clients for site %s by %s", site_id, distinct,
        )
        response = mistapi.api.v1.sites.clients.count.countSiteWirelessClients(     # actual SDK call
            self.apisession, site_id,                                               # required path arg
            distinct=distinct,                                                      # group-by selector
            start=(start or None), end=(end or None),                               # omit when blank
        )
        body = response.data or {}                                                  # normalize None to empty dict
        results = body.get("results") or []                                         # default to empty list when absent
        logging.debug(                                                              # after-API-call summary log
            "Count: distinct=%s total=%s results=%d",
            body.get("distinct"), body.get("total"), len(results),
        )

        logging.info("Flattening count summary for site %s", site_id)               # before-flatten action log
        summary_row = self._flatten_count_summary(site_id, body)                    # build one summary dict
        logging.debug("Flattened 1 summary row")                                    # after-flatten count log

        logging.info("Flattening %d result rows", len(results))                     # before-flatten action log
        result_rows = self._flatten_count_results(site_id, body, results)           # one row per distinct value
        logging.debug("Flattened %d result rows", len(result_rows))                 # after-flatten count log

        logging.info("Writing count summary via DataExporter")                      # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [summary_row],                                                          # list-of-rows interface
            filename=f"site_{site_id[:8]}_wireless_client_count_summary",           # human-friendly stem
            api_function_name="countSiteWirelessClients",                           # PK strategy lookup key
        )

        logging.info("Writing count results via DataExporter")                      # before-export action log
        DataExporter.write_with_format_selection(                                   # second multi-backend write
            result_rows,                                                            # may be empty list
            filename=f"site_{site_id[:8]}_wireless_client_count_results",           # human-friendly stem
            api_function_name="countSiteWirelessClientsResults",                    # MistHelper-internal sub-table key
        )
```

Helpers `_flatten_count_summary` and `_flatten_count_results` follow the same comment-
and log-density rules, stay under 25 lines, and live on the same
`SiteClientExportUtils` class -- no standalone wrapper functions.


The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 89 sits inside the standard sweep range, so a green run confirms the new
item works end to end against the site configured in `.env`.
