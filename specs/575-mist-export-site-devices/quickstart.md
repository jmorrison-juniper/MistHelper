# Phase 1 Quickstart: exportSiteDevices

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed (no new dependencies -- `base64` and `csv` are
  Python stdlib):

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this
file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_SITE_ID=<your-default-site-uuid>   # optional default for the site_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is never
written to logs or stdout. The decoded CSV content is never written to logs at
INFO or DEBUG -- only its byte length and resulting row count appear in the
log stream.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- CSV: `data/site_<first-8-of-site-uuid>_devices_export.csv`
- SQLite: `data/mist_data.db`, table `site_device_export`

## Skeleton of the new methods

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class SiteDeviceExportUtils:                                                        # existing class, no new wrapper

    def export_site_devices(self, site_id=None):                                    # menu 72 entrypoint
        logging.info("Prompting for site_id for device export menu item")           # before-prompt action log
        site_id = site_id or safe_input(                                            # honor caller override else prompt user
            "Site ID (UUID): ",                                                     # human-readable prompt text
            context="site_device_export:site_id",                                   # SSH/container EOF context tag
            default=os.environ.get("MIST_SITE_ID", ""),                             # fall back to .env default
        )
        if not is_valid_uuid(site_id):                                              # validate before any API call
            logging.warning("Invalid site_id %s -- aborting menu 72", site_id)      # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Exporting devices for site %s", site_id)                      # before-API-call action log
        response = mistapi.api.v1.sites.devices.export.exportSiteDevices(           # actual SDK call
            self.apisession, site_id,                                               # only required path param
        )
        payload = response.data                                                     # base64-encoded CSV scalar or wrapper
        logging.debug("Received %d bytes of base64 payload", len(payload or ""))    # after-API-call size log (no content)

        device_rows = self._decode_and_parse_device_csv(site_id, payload)           # decode + CSV-parse into dict rows
        if not device_rows:                                                         # handle empty / 404 / parse failure
            logging.warning("No device rows parsed for site %s", site_id)           # log empty result and exit cleanly
            return                                                                  # early return per safety-first principle

        logging.info("Writing site_device_export rows via DataExporter")            # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            device_rows,                                                            # list-of-rows interface
            filename=f"site_{site_id[:8]}_devices_export",                          # human-friendly stem
            api_function_name="exportSiteDevices",                                  # PK strategy lookup key
        )

    def _decode_and_parse_device_csv(self, site_id, payload):                       # private helper, same class
        logging.info("Decoding base64 payload for site %s", site_id)                # before-decode action log
        try:                                                                        # protect against malformed payload
            decoded_bytes = base64.b64decode(payload or "", validate=True)          # strict base64 decode
        except (binascii.Error, ValueError):                                        # malformed base64 input
            logging.exception("Base64 decode failed for site %s", site_id)          # full traceback at ERROR
            return []                                                               # return empty so caller exits cleanly
        decoded_text = decoded_bytes.decode("utf-8", errors="replace")              # Mist exports UTF-8 CSV
        logging.info("Parsing decoded CSV with csv.DictReader")                     # before-parse action log
        csv_reader = csv.DictReader(io.StringIO(decoded_text))                      # iterate rows as dicts keyed by header
        exported_at = datetime.now(timezone.utc).isoformat(timespec="seconds")      # audit timestamp for every row
        device_rows = [                                                             # list comprehension stays <=5 lines
            {**row, "site_id": site_id, "exported_at_utc": exported_at}             # inject FK + audit field
            for row in csv_reader                                                   # one dict per CSV line
        ]
        logging.debug("Parsed %d device rows from CSV", len(device_rows))           # after-parse count log
        return device_rows                                                          # caller writes via DataExporter
```

`_decode_and_parse_device_csv` stays under 25 lines and lives on the same
`SiteDeviceExportUtils` class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 72 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 72 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the site configured in `.env`.
