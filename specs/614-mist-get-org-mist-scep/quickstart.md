# Phase 1 Quickstart: getOrgMistScep

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

The endpoint also returns a Jamf access token (`jamf_access_token`). That value is
persisted to the configured output backend (CSV / SQLite / ArangoDB) but is never logged
above `DEBUG`, and at `DEBUG` only its *presence* (boolean) is logged -- never the value.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- CSV: `data/org_<first-8-of-org-uuid>_mist_scep_setting.csv` (one data row)
- SQLite: `data/mist_data.db`, table `org_setting_mist_scep` (one row per org, upserts on
  re-run)

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents the
expected shape so that inline comment and action logging coverage can be reviewed before
the code is written. Every executable line carries a `#` comment (Constitution VI), and
every meaningful action is bracketed by `logging.info()` / `logging.debug()` calls
(Constitution VII).

```python
class OrgSettingsExportUtils:                                                       # existing class, no new wrapper

    def export_org_mist_scep_setting(self, org_id=None):                            # menu 88 entrypoint
        logging.info("Prompting for org_id for Mist SCEP setting menu item")        # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_mist_scep:org_id",                                         # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 88", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Fetching Mist SCEP setting for org %s", org_id)               # before-API-call action log
        response = mistapi.api.v1.orgs.setting.mist_scep.getOrgMistScep(            # actual SDK call
            self.apisession, org_id,                                                # only path param required
        )
        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug(                                                              # after-API-call presence summary
            "Mist SCEP: enabled=%s suspended=%s providers=%d has_jamf_token=%s",
            body.get("enabled"), body.get("suspended"),
            len(body.get("cert_providers") or []),
            bool(body.get("jamf_access_token")),                                    # log PRESENCE only, never the value
        )

        logging.info("Flattening Mist SCEP setting payload for org %s", org_id)     # before-flatten action log
        setting_row = self._flatten_mist_scep_setting(org_id, body)                 # build one row dict
        logging.debug("Flattened 1 setting row")                                    # after-flatten count log

        logging.info("Writing Mist SCEP setting via DataExporter")                  # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [setting_row],                                                          # list-of-rows interface
            filename=f"org_{org_id[:8]}_mist_scep_setting",                         # human-friendly stem
            api_function_name="getOrgMistScep",                                     # PK strategy lookup key
        )
```

The `_flatten_mist_scep_setting` helper follows the same comment- and log-density rules,
stays under 25 lines, and lives on the same `OrgSettingsExportUtils` class -- no
standalone wrapper functions. Its body joins `body.get("cert_providers") or []` with a
comma into the `cert_providers` CSV string column documented in `data-model.md`, copies
the URL fields, coerces booleans to 0/1 for SQLite, and stamps `polled_at_utc` with the
current UTC time in ISO 8601 format.


The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,

## Sanity check after first run

After a successful run, verify the SQLite table and confirm the sensitive Jamf token is
persisted to the database but never appears in any log file.

Inspect the row count and column presence in SQLite:

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/mist_data.db'); r=c.execute('SELECT org_id, enabled, suspended, cert_providers, cert_providers_count, CASE WHEN jamf_access_token IS NOT NULL AND jamf_access_token != '''' THEN ''<present>'' ELSE ''<absent>'' END AS jamf_token FROM org_setting_mist_scep').fetchall(); [print(row) for row in r]"
```

Confirm the Jamf token never leaked into any log file under `data/`:

```powershell
Select-String -Path "data\*.log" -Pattern "jamf_access_token" -ErrorAction SilentlyContinue
# Expected: zero matches. The token must never appear in any log file.
```
