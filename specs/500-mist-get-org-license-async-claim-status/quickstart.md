# Phase 1 Quickstart: GetOrgLicenseAsyncClaimStatus

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-28

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- Summary CSV: `data/org_<first-8-of-org-uuid>_claim_status_summary.csv`
- Detail CSV: `data/org_<first-8-of-org-uuid>_claim_status_details.csv`
  (only emitted when the user answers `y` to the detail prompt)
- SQLite: `data/mist_data.db`, tables `org_claim_status_summary` and
  `org_claim_status_details`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents the
expected shape so that inline comment and action logging coverage can be reviewed before
the code is written. Every executable line carries a `#` comment (Constitution VI), and
every meaningful action is bracketed by `logging.info()` / `logging.debug()` calls
(Constitution VII).

```python
class LicenseExportUtils:                                                           # existing class, no new wrapper

    def export_org_license_async_claim_status(self, org_id=None, include_detail=False):  # menu 95 entrypoint
        logging.info("Prompting for org_id for async claim status menu item")       # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_license_claim_status:org_id",                              # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 95", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for detail flag")                                   # before-prompt action log
        detail_answer = safe_input(                                                 # ask whether to include per-device detail
            "Include per-device detail? (y/N): ",                                   # default is N
            context="org_license_claim_status:detail",                              # EOF context tag
            default="N",                                                            # explicit default for non-interactive runs
        )
        include_detail = detail_answer.strip().lower() in ("y", "yes")              # normalize user answer to bool

        logging.info("Fetching async claim status for org %s", org_id)              # before-API-call action log
        response = mistapi.api.v1.orgs.claim.status.getOrgLicenseAsyncClaimStatus(  # actual SDK call
            self.apisession, org_id, detail=include_detail or None,                 # omit query param when False
        )
        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug(                                                              # after-API-call summary log
            "Claim status: status=%s total=%s succeed=%s failed=%s",
            body.get("status"), body.get("total"), body.get("succeed"), body.get("failed"),
        )

        logging.info("Flattening summary payload for org %s", org_id)               # before-flatten action log
        summary_row = self._flatten_claim_summary(org_id, body)                     # build one summary dict
        logging.debug("Flattened 1 summary row")                                    # after-flatten count log

        logging.info("Writing claim status summary via DataExporter")               # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [summary_row],                                                          # list-of-rows interface
            filename=f"org_{org_id[:8]}_claim_status_summary",                      # human-friendly stem
            api_function_name="getOrgLicenseAsyncClaimStatus",                      # PK strategy lookup key
        )

        if include_detail:                                                          # only when caller asked for detail
            detail_rows = self._flatten_claim_details(org_id, body)                 # one row per device MAC
            logging.debug("Flattened %d detail rows", len(detail_rows))             # after-flatten count log
            logging.info("Writing claim status detail via DataExporter")            # before-export action log
            DataExporter.write_with_format_selection(                               # second multi-backend write
                detail_rows,                                                        # may be empty list when no devices
                filename=f"org_{org_id[:8]}_claim_status_details",                  # human-friendly stem
                api_function_name="getOrgLicenseAsyncClaimStatusDetails",           # MistHelper-internal sub-table key
            )
```

Helpers `_flatten_claim_summary` and `_flatten_claim_details` follow the same comment-
and log-density rules, stay under 25 lines, and live on the same `LicenseExportUtils`
class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 95 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 95 sits inside the standard sweep range, so a green run confirms the new
item works end to end against the org configured in `.env`.
