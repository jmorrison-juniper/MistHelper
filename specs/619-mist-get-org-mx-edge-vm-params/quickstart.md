# Phase 1 Quickstart: getOrgMxEdgeVmParams

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>        # optional default for the org_id prompt
MIST_MXEDGE_ID=<your-default-mxedge-uuid>  # optional default for the mxedge_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout. The `MIST_MXEDGE_ID` variable is new for
this feature; add a matching template line to `deploy/.env.example` in the
same PR.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it
with `chmod -R 777 data/` on Linux first to satisfy the non-root container
user).

- CSV: `data/org_<first-8-of-org-uuid>_mxedge_<first-8-of-mxedge-uuid>_vm_params.csv`
- SQLite: `data/mist_data.db`, table `org_mxedge_vm_params`
- ArangoDB / Redis: collection / key namespace `org_mxedge_vm_params`
  (handled by `DataExporter`; no manual setup required beyond having the
  polyglot containers up).

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class MxEdgeExportUtils:                                                            # existing class, no new wrapper

    def export_org_mxedge_vm_params(self, org_id=None, mxedge_id=None):             # menu 91 entrypoint
        logging.info("Prompting for org_id for mxedge VM params menu item")         # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_mxedge_vm_params:org_id",                                  # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 91", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for mxedge_id for mxedge VM params menu item")      # before-prompt action log
        mxedge_id = mxedge_id or safe_input(                                        # honor caller override else prompt user
            "Mist Edge ID (UUID): ",                                                # human-readable prompt text
            context="org_mxedge_vm_params:mxedge_id",                               # SSH/container EOF context tag
            default=os.environ.get("MIST_MXEDGE_ID", ""),                           # fall back to .env default
        )
        if not is_valid_uuid(mxedge_id):                                            # validate before any API call
            logging.warning("Invalid mxedge_id %s -- aborting menu 91", mxedge_id)  # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Fetching VM params for mxedge %s in org %s",                  # before-API-call action log
                     mxedge_id, org_id)
        response = mistapi.api.v1.orgs.mxedges.vm_params.getOrgMxEdgeVmParams(      # actual SDK call
            self.apisession, org_id, mxedge_id,                                     # both required path params
        )
        body = response.data or {}                                                  # normalize None to empty dict
        user_data_b64 = body.get("user_data", "") or ""                             # extract sensitive field once
        sha256_hex = hashlib.sha256(user_data_b64.encode()).hexdigest()             # cheap change-detection digest
        logging.debug(                                                              # sanitized after-API-call summary log
            "VM params: model=%s name=%s user_data_len=%d user_data_sha256_prefix=%s",
            body.get("model"), body.get("name"),
            len(user_data_b64), sha256_hex[:6],                                     # never log raw user_data
        )

        logging.info("Flattening VM params payload for mxedge %s", mxedge_id)       # before-flatten action log
        flattened_row = self._flatten_mxedge_vm_params(                             # build one dict row
            org_id, mxedge_id, body, user_data_b64, sha256_hex,
        )
        logging.debug("Flattened 1 row")                                            # after-flatten count log

        logging.info("Writing VM params via DataExporter")                          # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [flattened_row],                                                        # list-of-rows interface
            filename=f"org_{org_id[:8]}_mxedge_{mxedge_id[:8]}_vm_params",          # human-friendly stem
            api_function_name="getOrgMxEdgeVmParams",                               # PK strategy lookup key
        )
```

The private helper `_flatten_mxedge_vm_params` follows the same comment- and
log-density rules, stays under 25 lines, and lives on the same
`MxEdgeExportUtils` class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 91 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 91 sits just outside the 90-100 skip block, so a green
run confirms the new item works end to end against the org and mxedge
configured in `.env`. If task generation must move the menu number into the
90-100 range, the skip list is updated to keep 91 (or its replacement) in
the sweep.
