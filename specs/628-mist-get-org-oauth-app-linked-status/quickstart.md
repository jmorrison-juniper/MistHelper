# Phase 1 Quickstart: getOrgOauthAppLinkedStatus

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new menu
item on a Windows 11 dev box. Container parity is identical -- paths normalize via
`pathlib.Path` and `os.path.join`.

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell inside the Linux container).
- Python 3.13 or newer on `PATH`.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this
file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>            # optional default for prompt 1
MIST_OAUTH_APP_NAME=jamf                       # optional default for prompt 2
MIST_OAUTH_FORWARD_URL=https://manage.mist.com/admin/   # optional default for prompt 3
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`.
The API token is consumed by `mistapi.APISession` and is never written to logs or
stdout.

## Expected output filenames

Files land under `data/`. On Linux hosts / inside the container run
`chmod -R 777 data/` once to satisfy the non-root container user.

- Summary CSV:
  `data/org_<first-8-of-org-uuid>_<app_name>_oauth_link_summary.csv`
- Accounts CSV:
  `data/org_<first-8-of-org-uuid>_<app_name>_oauth_link_accounts.csv`
- SQLite: `data/mist_data.db`, tables `org_oauth_app_link_summary` and
  `org_oauth_app_link_accounts`.

The CSV writer omits the `authorization_url` column (contains a redirect nonce);
SQLite / ArangoDB retain it under controlled file permissions.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so inline-comment and action-logging coverage can be
reviewed before code is written. Every executable line carries a `#` comment
(Constitution VI); every meaningful action is bracketed by `logging.info()` /
`logging.debug()` calls (Constitution VII).

```python
class OrgSettingsExportUtils:                                                          # existing class, no new wrapper

    def export_org_oauth_app_linked_status(self, org_id=None, app_name=None,           # menu 58 entrypoint
                                           forward_url=None):
        logging.info("Prompting for org_id for OAuth link status menu item")           # before-prompt action log
        org_id = org_id or safe_input(                                                 # honor caller override else prompt user
            "Org ID (UUID): ",                                                         # human-readable prompt text
            context="org_oauth_link_status:org_id",                                    # SSH / container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                                 # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                                  # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 58", org_id)           # log failure (no traceback)
            return                                                                     # early return per safety-first

        logging.info("Prompting for app_name")                                         # before-prompt action log
        app_name = (app_name or safe_input(                                            # prompt or fallback
            "App name (jamf, crowdstrike, zoom, zscaler, prisma, zdx, ...): ",        # prompt text lists common values
            context="org_oauth_link_status:app_name",                                  # EOF context tag
            default=os.environ.get("MIST_OAUTH_APP_NAME", ""),                         # fall back to .env default
        )).strip().lower()                                                             # normalize to lowercase, strip
        if not APP_NAME_PATTERN.match(app_name):                                       # validate against compiled regex
            logging.warning("Invalid app_name %s -- aborting menu 58", app_name)       # log validation failure
            return                                                                     # early return

        logging.info("Prompting for forward URL")                                      # before-prompt action log
        forward_url = forward_url or safe_input(                                       # prompt or fallback
            "Forward URL (https:// where Mist redirects after OAuth): ",               # prompt text
            context="org_oauth_link_status:forward",                                   # EOF context tag
            default=os.environ.get("MIST_OAUTH_FORWARD_URL",                           # .env default
                                   "https://manage.mist.com/admin/"),
        )
        parsed = urllib.parse.urlparse(forward_url)                                    # structural URL validation
        if parsed.scheme != "https" or not parsed.netloc:                              # must be https + non-empty host
            logging.warning("Invalid forward URL -- aborting menu 58")                 # log; do NOT echo url (may be edited)
            return                                                                     # early return

        logging.info("Fetching OAuth link status for org %s app %s", org_id, app_name) # before-API-call action log
        response = mistapi.api.v1.orgs.setting.link_accounts.getOrgOauthAppLinkedStatus(  # actual SDK call
            self.apisession, org_id, app_name, forward=forward_url,                    # required path + query params
        )
        body = response.data or {}                                                     # normalize None to empty dict
        accounts = body.get("accounts") or []                                          # normalize None list to []
        logging.debug("OAuth link status: linked=%s accounts=%d",                      # after-API-call summary log
                      body.get("linked"), len(accounts))                               # no authorization_url in logs

        logging.info("Flattening OAuth link summary payload")                          # before-flatten action log
        summary_row = self._flatten_oauth_link_summary(org_id, app_name, body)         # build one summary dict
        logging.debug("Flattened 1 summary row")                                       # after-flatten count log

        logging.info("Flattening %d OAuth linked account rows", len(accounts))         # before-flatten action log
        account_rows = self._flatten_oauth_link_accounts(org_id, app_name, accounts)   # build one row per account
        logging.debug("Flattened %d account rows", len(account_rows))                  # after-flatten count log

        logging.info("Writing OAuth link summary via DataExporter")                    # before-export action log
        DataExporter.write_with_format_selection(                                      # multi-backend write
            [summary_row],                                                             # list-of-rows interface
            filename=f"org_{org_id[:8]}_{app_name}_oauth_link_summary",                # human-friendly stem
            api_function_name="getOrgOauthAppLinkedStatus",                            # PK strategy lookup key
        )

        logging.info("Writing OAuth link accounts via DataExporter")                   # before-export action log
        DataExporter.write_with_format_selection(                                      # second multi-backend write
            account_rows,                                                              # may be empty list when unlinked
            filename=f"org_{org_id[:8]}_{app_name}_oauth_link_accounts",               # human-friendly stem
            api_function_name="getOrgOauthAppLinkedStatusAccounts",                    # MistHelper-internal sub-table key
        )
```

Helpers `_flatten_oauth_link_summary` and `_flatten_oauth_link_accounts` obey the
same comment- and log-density rules, stay under 25 lines, and live on the same
`OrgSettingsExportUtils` class -- no standalone wrapper functions. Both explicitly
redact `password`, `webhook_password`, `webhook_secret`, and `webhook_token` before
row construction, replacing them with `has_*` boolean flags per the data model.

## Quality gates (all must pass before commit)

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 58 included)
```

The `--test` sweep automatically skips heavy / destructive operations (14, 18,
63-65, 90-100). Menu 58 sits inside the standard sweep range, so a green run
confirms the new item works end-to-end against the org and integration configured
in `.env`.
