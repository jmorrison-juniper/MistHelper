# Phase 1 Quickstart: getOrgMxTunnel

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>           # optional default for the org_id prompt
MIST_MXTUNNEL_ID=<your-default-mxtunnel-uuid> # optional default for the mxtunnel_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- Summary CSV: `data/org_<first-8-of-org-uuid>_mxtunnel_<first-8-of-mxtunnel-uuid>.csv`
- IPSec extra-routes CSV:
  `data/org_<first-8-of-org-uuid>_mxtunnel_<first-8-of-mxtunnel-uuid>_ipsec_extra_routes.csv`
  (only emitted when the mxtunnel has at least one entry in `ipsec.extra_routes`)
- SQLite: `data/mist_data.db`, tables `org_mxtunnels` and
  `org_mxtunnel_ipsec_extra_routes`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before the code is written. Every executable line carries a `#` comment (Constitution
VI), and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class MxTunnelExportUtils:                                                          # new class, no wrapper functions

    def __init__(self, apisession):                                                 # ctor receives a logged-in APISession
        self.apisession = apisession                                                # stash for later SDK calls

    def export_org_mxtunnel(self, org_id=None, mxtunnel_id=None):                   # menu 96 entrypoint
        logging.info("Prompting for org_id for mxtunnel menu item")                 # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_mxtunnel:org_id",                                          # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 96", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for mxtunnel_id")                                   # before-prompt action log
        mxtunnel_id = mxtunnel_id or safe_input(                                    # honor caller override else prompt user
            "MxTunnel ID (UUID): ",                                                 # human-readable prompt text
            context="org_mxtunnel:mxtunnel_id",                                     # EOF context tag
            default=os.environ.get("MIST_MXTUNNEL_ID", ""),                         # fall back to .env default
        )
        if not is_valid_uuid(mxtunnel_id):                                          # validate before any API call
            logging.warning("Invalid mxtunnel_id %s -- aborting", mxtunnel_id)      # log validation failure
            return                                                                  # early return per safety-first principle

        logging.info("Fetching mxtunnel %s for org %s", mxtunnel_id, org_id)        # before-API-call action log
        response = mistapi.api.v1.orgs.mxtunnels.getOrgMxTunnel(                    # actual SDK call (one-shot, no pagination)
            self.apisession, org_id, mxtunnel_id,                                   # both UUIDs required
        )
        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug(                                                              # after-API-call summary log
            "Mxtunnel: name=%s protocol=%s mxclusters=%d vlan_ids=%d",
            body.get("name"), body.get("protocol"),
            len(body.get("mxcluster_ids") or []), len(body.get("vlan_ids") or []),
        )

        logging.info("Flattening mxtunnel summary payload")                         # before-flatten action log
        summary_row = self._flatten_mxtunnel_summary(body)                          # one parent row
        logging.debug("Flattened 1 summary row")                                    # after-flatten count log

        extra_routes = (body.get("ipsec") or {}).get("extra_routes") or []          # safe nested access
        logging.info("Flattening %d IPSec extra-route rows", len(extra_routes))     # before-flatten action log
        extra_route_rows = self._flatten_mxtunnel_extra_routes(body, extra_routes)  # child rows
        logging.debug("Flattened %d extra-route rows", len(extra_route_rows))       # after-flatten count log

        logging.info("Writing mxtunnel summary via DataExporter")                   # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [summary_row],                                                          # list-of-rows interface
            filename=f"org_{org_id[:8]}_mxtunnel_{mxtunnel_id[:8]}",                # human-friendly stem
            api_function_name="getOrgMxTunnel",                                     # PK strategy lookup key
        )

        if extra_route_rows:                                                        # only emit child file when non-empty
            logging.info("Writing mxtunnel IPSec extra routes via DataExporter")    # before-export action log
            DataExporter.write_with_format_selection(                               # second multi-backend write
                extra_route_rows,                                                   # one row per (mxtunnel, dest, next_hop)
                filename=f"org_{org_id[:8]}_mxtunnel_{mxtunnel_id[:8]}_ipsec_extra_routes",  # child stem
                api_function_name="getOrgMxTunnelIpsecExtraRoutes",                 # MistHelper-internal sub-table key
            )
```

Helpers `_flatten_mxtunnel_summary` and `_flatten_mxtunnel_extra_routes` follow the same
comment- and log-density rules, stay under 25 lines, and live on the same
`MxTunnelExportUtils` class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 96 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 96 sits inside the standard sweep range, so a green run confirms the new
item works end to end against the org / mxtunnel pair configured in `.env`.
