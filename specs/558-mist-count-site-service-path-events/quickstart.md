# Phase 1 Quickstart: countSiteServicePathEvents

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_SITE_ID=<your-default-site-uuid>   # optional default for the site_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it
with `chmod -R 777 data/` on Linux first to satisfy the non-root container
user).

- CSV: `data/site_<first-8-of-site-uuid>_service_path_events_count_<distinct_field>.csv`
- SQLite: `data/mist_data.db`, table `site_service_path_events_count`
- ArangoDB / Redis: collection `site_service_path_events_count` and matching
  Redis key namespace (handled by `DataExporter`).

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class SiteEventsExportUtils:                                                          # existing class, no new wrapper

    DISTINCT_ENUM = (                                                                 # documented enum from OpenAPI
        "type", "vpn_name", "vpn_path", "policy",                                     # service-path identification fields
        "port_id", "model", "version", "mac",                                         # device identification fields
    )

    def export_site_service_path_events_count(                                        # menu 96 entrypoint
        self,
        site_id=None,                                                                 # optional caller override
        distinct_field=None,                                                          # optional caller override
        window_start=None,                                                            # optional caller override
        window_end=None,                                                              # optional caller override
    ):
        logging.info("Prompting for site_id for service-path events count menu item") # before-prompt action log
        site_id = site_id or safe_input(                                              # honor caller override else prompt
            "Site ID (UUID): ",                                                       # human-readable prompt text
            context="site_service_path_events_count:site_id",                         # SSH/container EOF context tag
            default=os.environ.get("MIST_SITE_ID", ""),                               # fall back to .env default
        )
        if not is_valid_uuid(site_id):                                                # validate before any API call
            logging.warning("Invalid site_id %s -- aborting menu 96", site_id)        # log validation failure (no traceback)
            return                                                                    # early return per safety-first principle

        logging.info("Prompting for distinct field")                                  # before-prompt action log
        distinct_field = (distinct_field or safe_input(                               # honor caller override else prompt
            "Group by distinct field "                                                # prompt with enum hint
            "[type|vpn_name|vpn_path|policy|port_id|model|version|mac] "
            "(default: type): ",
            context="site_service_path_events_count:distinct",                        # EOF context tag
            default="type",                                                           # NOC-friendly default
        )).strip().lower()
        if distinct_field not in self.DISTINCT_ENUM:                                  # enum guard before API call
            logging.warning("Invalid distinct field %s -- aborting", distinct_field)  # log + early return
            return

        logging.info("Prompting for window start")                                    # before-prompt action log
        window_start = window_start if window_start is not None else safe_input(      # honor caller override
            "Start of window (epoch seconds OR relative like '-1d', '-1w'; "          # explicit format hint
            "blank for default 1d window): ",
            context="site_service_path_events_count:start",                           # EOF context tag
            default="",                                                               # blank -> SDK uses duration=1d
        )
        logging.info("Prompting for window end")                                      # before-prompt action log
        window_end = window_end if window_end is not None else safe_input(            # honor caller override
            "End of window (epoch seconds OR relative like 'now', '-1h'; "            # explicit format hint
            "blank for now): ",
            context="site_service_path_events_count:end",                             # EOF context tag
            default="",                                                               # blank -> SDK omits and server defaults
        )

        logging.info(                                                                 # before-API-call action log
            "Counting service path events for site %s distinct=%s window=%s..%s",
            site_id, distinct_field, window_start or "(default)", window_end or "(now)",
        )
        response = mistapi.api.v1.sites.services.events.count.countSiteServicePathEvents(  # actual SDK call
            self.apisession,
            site_id,
            distinct=distinct_field,                                                  # grouping field
            start=window_start or None,                                               # pass-through; None lets SDK skip param
            end=window_end or None,                                                   # pass-through; None lets SDK skip param
        )
        body = response.data or {}                                                    # normalize None to empty dict
        buckets = body.get("results", []) or []                                       # default to empty list
        logging.debug(                                                                # after-API-call summary log
            "Count response: total=%s buckets=%d",
            body.get("total"), len(buckets),
        )

        logging.info("Flattening %d result buckets for site %s", len(buckets), site_id)  # before-flatten log
        bucket_rows = self._flatten_count_buckets(                                    # private helper on same class
            site_id, distinct_field, body, buckets,
        )
        logging.debug("Flattened %d bucket rows", len(bucket_rows))                   # after-flatten count log

        logging.info("Writing service path events count via DataExporter")            # before-export action log
        DataExporter.write_with_format_selection(                                     # multi-backend write
            bucket_rows,                                                              # list-of-rows interface
            filename=(                                                                # deterministic stem
                f"site_{site_id[:8]}_service_path_events_count_{distinct_field}"
            ),
            api_function_name="countSiteServicePathEvents",                           # PK strategy lookup key
        )
```

The helper `_flatten_count_buckets` follows the same comment- and
log-density rules, stays under 25 lines, and lives on the same
`SiteEventsExportUtils` class -- no standalone wrapper functions.

```powershell

python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 96 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 96 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the site configured in `.env`.
