# Phase 1 Quickstart: getOrgServicePolicy

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this
file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`.
The API token is consumed by `mistapi.APISession` and is never written to logs
or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- Parent CSV:
  `data/org_<first-8-of-org-uuid>_service_policy_<first-8-of-policy-uuid>.csv`
- EWF child CSV:
  `data/org_<first-8-of-org-uuid>_service_policy_<first-8-of-policy-uuid>_ewf.csv`
  (only emitted when the response contains a non-empty `ewf` array)
- SQLite: `data/mist_data.db`, tables `org_service_policy` (parent) and
  `org_service_policy_ewf` (children)

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging coverage
can be reviewed before the code is written. Every executable line carries a `#`
comment (Constitution VI), and every meaningful action is bracketed by
`logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class OrgServicePolicyExportUtils:                                                  # existing class, no new wrapper

    def export_org_service_policy_detail(self, org_id=None, servicepolicy_id=None): # menu 94 entrypoint
        logging.info("Prompting for org_id for service policy detail menu item")    # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_service_policy:org_id",                                    # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 94", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for servicepolicy_id")                              # before-prompt action log
        servicepolicy_id = servicepolicy_id or safe_input(                          # honor caller override else prompt
            "Service Policy ID (UUID) [run menu 4 to list all policies first]: ",   # helpful hint for junior NOC users
            context="org_service_policy:servicepolicy_id",                          # EOF context tag
            default="",                                                             # no .env default for per-object IDs
        )
        if not is_valid_uuid(servicepolicy_id):                                     # validate before any API call
            logging.warning("Invalid servicepolicy_id %s -- aborting", servicepolicy_id)  # log validation failure
            return                                                                  # early return per safety-first principle

        logging.info("Fetching service policy %s for org %s", servicepolicy_id, org_id)  # before-API-call action log
        response = mistapi.api.v1.orgs.servicepolicies.getOrgServicePolicy(         # actual SDK call
            self.apisession, org_id, servicepolicy_id,                              # required path params
        )
        body = response.data or {}                                                  # normalize None to empty dict
        ewf_rules = body.get("ewf") or []                                           # ewf array may be absent
        logging.debug(                                                              # after-API-call summary log
            "Service policy: name=%s action=%s ewf_rules=%d services=%d tenants=%d",
            body.get("name"), body.get("action"), len(ewf_rules),
            len(body.get("services") or []), len(body.get("tenants") or []),
        )

        logging.info("Flattening service policy parent payload")                    # before-flatten action log
        parent_row = self._flatten_service_policy(org_id, body, len(ewf_rules))     # build one parent dict
        logging.debug("Flattened 1 parent row")                                     # after-flatten count log

        logging.info("Flattening %d ewf rule rows", len(ewf_rules))                 # before-flatten action log
        ewf_rows = self._flatten_service_policy_ewf(org_id, body.get("id"), ewf_rules)  # one row per array element
        logging.debug("Flattened %d ewf rule rows", len(ewf_rows))                  # after-flatten count log

        logging.info("Writing service policy parent via DataExporter")              # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [parent_row],                                                           # list-of-rows interface
            filename=f"org_{org_id[:8]}_service_policy_{servicepolicy_id[:8]}",     # human-friendly stem
            api_function_name="getOrgServicePolicy",                                # PK strategy lookup key
        )
        if ewf_rows:                                                                # only when there are children
            logging.info("Writing service policy ewf rules via DataExporter")       # before-export action log
            DataExporter.write_with_format_selection(                               # second multi-backend write
                ewf_rows,                                                           # list of child rows
                filename=f"org_{org_id[:8]}_service_policy_{servicepolicy_id[:8]}_ewf",  # human-friendly stem
                api_function_name="getOrgServicePolicyEwfRules",                    # MistHelper-internal sub-table key
            )
```

Helpers `_flatten_service_policy` and `_flatten_service_policy_ewf` follow the
same comment- and log-density rules, stay under 25 lines each, and live on the
same class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 94 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 94 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the org configured in `.env`.
`--test` requires a valid `MIST_ORG_ID` in `.env` and at least one existing
service policy in that org (either pre-existing or created out-of-band; the
sibling `listOrgServicePolicies` at menu 4 can be used to enumerate a valid
`servicepolicy_id`).
