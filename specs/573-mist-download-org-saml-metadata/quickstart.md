# Phase 1 Quickstart: downloadOrgSamlMetadata

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
MIST_SSO_ID=<your-default-sso-uuid>   # optional default for the sso_id prompt; used by --test
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- CSV: `data/org_<first-8-of-org-uuid>_sso_<first-8-of-sso-uuid>_saml_metadata.csv`
- SQLite: `data/mist_data.db`, table `org_sso_saml_metadata`
- ArangoDB collection (when the polyglot backend is active): `org_sso_saml_metadata`

The CSV contains one row per invocation. Re-running against the same `(org_id, sso_id)`
upserts (no duplicates) -- the rotation signal is the changing `metadata_sha256`
column across polls.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before the code is written. Every executable line carries a `#` comment (Constitution
VI), and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class OrgExportUtils:                                                               # existing class, no new wrapper

    def export_org_saml_metadata(self, org_id=None, sso_id=None):                   # menu 95 entrypoint
        logging.info("Prompting for org_id for SAML metadata menu item")            # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_saml_metadata:org_id",                                     # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 95", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for sso_id for SAML metadata menu item")            # before-prompt action log
        sso_id = sso_id or safe_input(                                              # honor caller override else prompt user
            "SSO ID (UUID): ",                                                      # human-readable prompt text
            context="org_saml_metadata:sso_id",                                     # SSH/container EOF context tag
            default=os.environ.get("MIST_SSO_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(sso_id):                                               # validate before any API call
            logging.warning("Invalid sso_id %s -- aborting menu 95", sso_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Fetching SAML metadata for org %s sso %s", org_id, sso_id)    # before-API-call action log
        response = mistapi.api.v1.orgs.ssos.metadata_xml.downloadOrgSamlMetadata(   # actual SDK call (returns XML)
            self.apisession, org_id, sso_id,                                        # two required path params, no query
        )
        xml_text = self._normalize_xml_body(response.data)                          # str / bytes / None -> str
        body_bytes = len(xml_text.encode("utf-8"))                                  # cheap change-detection signal
        body_sha = hashlib.sha256(xml_text.encode("utf-8")).hexdigest()             # 64-char rotation fingerprint
        logging.debug("SAML metadata received: %d bytes sha256=%s",                 # after-API-call summary log
                      body_bytes, body_sha[:8] + "..." + body_sha[-4:])             # log a truncated digest only

        logging.info("Flattening SAML metadata payload for org %s sso %s",          # before-flatten action log
                     org_id, sso_id)
        metadata_row = self._flatten_saml_metadata(                                 # build one dict row
            org_id, sso_id, xml_text, body_bytes, body_sha,                         # all PK + payload fields
        )
        logging.debug("Flattened 1 metadata row")                                   # after-flatten count log

        logging.info("Writing SAML metadata via DataExporter")                      # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [metadata_row],                                                         # list-of-rows interface
            filename=f"org_{org_id[:8]}_sso_{sso_id[:8]}_saml_metadata",            # human-friendly stem
            api_function_name="downloadOrgSamlMetadata",                            # PK strategy lookup key
        )
```

Helpers `_normalize_xml_body` and `_flatten_saml_metadata` follow the same comment- and
log-density rules, stay under 25 lines, and live on the same class -- no standalone
wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 95 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 95 sits inside the standard sweep range, so a green run confirms the new
item works end to end against the org/SSO configured in `.env`.
