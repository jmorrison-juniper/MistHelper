# Phase 1 Quickstart: countSiteDeviceConfigHistory

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_SITE_ID=<your-default-site-uuid>   # optional default for the site_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it
with `chmod -R 777 data/` on Linux first to satisfy the non-root container
user).

- Summary CSV:
  `data/site_<first-8-of-site-uuid>_config_history_count_summary.csv`
- Results CSV:
  `data/site_<first-8-of-site-uuid>_config_history_count_results.csv`
- SQLite: `data/mist_data.db`, tables
  `site_device_config_history_count_summary` and
  `site_device_config_history_count_results`.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline-comment and action-logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class SiteDevicesExportUtils:                                                     # existing class, no wrapper

    def export_site_device_config_history_count(                                  # menu 73 entrypoint
        self, site_id=None, distinct="mac", time_window="1d", limit=100,
    ):
        logging.info("Prompting for site_id for config-history count menu item")  # before-prompt action log
        site_id = site_id or safe_input(                                          # honor caller override else prompt user
            "Site ID (UUID): ",                                                   # human-readable prompt text
            context="site_device_config_history_count:site_id",                   # SSH/container EOF context tag
            default=os.environ.get("MIST_SITE_ID", ""),                           # fall back to .env default
        )
        if not is_valid_uuid(site_id):                                            # validate before any API call
            logging.warning("Invalid site_id %s -- aborting menu 73", site_id)    # log validation failure (no traceback)
            return                                                                # early return per safety-first principle

        distinct_field = safe_input(                                              # ask which field to group by
            "Distinct field to group by [mac]: ",                                 # default mac is most common
            context="site_device_config_history_count:distinct",                  # EOF context tag
            default="mac",                                                        # default value
        ) or "mac"                                                                # empty string normalizes to default

        mac_filter = safe_input(                                                  # optional per-device filter
            "Filter to a specific device MAC (blank for all): ",                  # blank means omit query param
            context="site_device_config_history_count:mac",                       # EOF context tag
            default="",                                                           # explicit blank default
        )

        duration_param = safe_input(                                              # time window knob
            "Time window duration [1d]: ",                                        # accepts 1d, 7d, 2w...
            context="site_device_config_history_count:duration",                  # EOF context tag
            default="1d",                                                         # API default
        ) or "1d"                                                                 # empty normalizes to default

        limit_param = self._coerce_limit(                                         # int coercion helper on same class
            safe_input(                                                           # prompt for page size
                "Result limit [100]: ",                                           # API default 100
                context="site_device_config_history_count:limit",                 # EOF context tag
                default="100",                                                    # explicit default
            ),
            fallback=100,                                                         # used when int() raises
        )

        logging.info(                                                             # before-API-call action log
            "Counting device config history entries for site %s distinct=%s",
            site_id, distinct_field,
        )
        response = mistapi.api.v1.sites.devices.config_history.count.countSiteDeviceConfigHistory(  # SDK call (URL-based path)
            self.apisession,                                                      # authenticated session
            site_id,                                                              # required path param
            distinct=distinct_field,                                              # which field to group by
            mac=mac_filter or None,                                               # omit when blank
            duration=duration_param,                                              # window knob
            limit=limit_param,                                                    # page size
        )
        body = response.data or {}                                                # normalize None to empty dict
        logging.debug(                                                            # after-API-call summary log
            "Count results: total=%s returned=%s",
            body.get("total"), len(body.get("results") or []),
        )

        logging.info("Flattening count summary")                                  # before-flatten action log
        summary_row = self._flatten_count_summary(                                # one summary dict
            site_id, distinct_field, mac_filter, duration_param, body,
        )
        logging.debug("Flattened 1 summary row")                                  # after-flatten count log

        logging.info(                                                             # before-flatten action log
            "Flattening %d result rows", len(body.get("results") or []),
        )
        result_rows = self._flatten_count_results(                                # one row per results[] entry
            site_id, distinct_field, summary_row, body,
        )
        logging.debug("Flattened %d result rows", len(result_rows))               # after-flatten count log

        logging.info("Writing config history count summary via DataExporter")    # before-export action log
        DataExporter.write_with_format_selection(                                 # multi-backend write
            [summary_row],                                                        # list-of-rows interface
            filename=f"site_{site_id[:8]}_config_history_count_summary",          # human-friendly stem
            api_function_name="countSiteDeviceConfigHistory",                     # PK strategy lookup key
        )

        logging.info("Writing config history count results via DataExporter")    # before-export action log
        DataExporter.write_with_format_selection(                                 # multi-backend write
            result_rows,                                                          # may be empty list
            filename=f"site_{site_id[:8]}_config_history_count_results",          # human-friendly stem
            api_function_name="countSiteDeviceConfigHistoryResults",              # MistHelper-internal sub-table key
        )
```

Helpers `_flatten_count_summary`, `_flatten_count_results`, and
`_coerce_limit` follow the same comment- and log-density rules, stay under
25 lines, and live on the same class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 73 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 73 sits inside the standard sweep range, so a green run
confirms the new item works end-to-end against the site configured in
`.env`.
