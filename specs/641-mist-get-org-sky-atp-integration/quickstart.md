# Phase 1 Quickstart: GetOrgSkyAtpIntegration

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the
new menu item on a Windows 11 dev box. Container parity is identical
(paths normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never
commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>
```

The `MIST_ORG_ID` value is optional -- it becomes the default when the
menu prompts for `org_id`. Loading is handled by the existing
`python-dotenv` bootstrap in `MistHelper.py`. The API token is consumed
by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create
it with `chmod -R 777 data/` on Linux first to satisfy the non-root
container user).

- Summary CSV: `data/org_<first-8-of-org-uuid>_sky_atp_integration.csv`
- Feeds CSV: `data/org_<first-8-of-org-uuid>_sky_atp_threat_feeds.csv`
  (may be empty when the org has no third-party threat feeds enabled)
- SQLite: `data/mist_data.db`, tables `org_sky_atp_integration` and
  `org_sky_atp_threat_feeds`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this
skeleton documents the expected shape so that inline comment and action
logging coverage can be reviewed before the code is written. Every
executable line carries a `#` comment (Constitution VI), and every
meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class OrgSecuritySettingsUtils:                                                     # new class per Principle II (no wrapper functions)

    def export_org_sky_atp_integration(self, org_id=None):                          # menu 96 entrypoint
        logging.info("Prompting for org_id for Sky ATP integration menu item")      # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_sky_atp_integration:org_id",                               # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 96", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Fetching Sky ATP integration for org %s", org_id)             # before-API-call action log
        response = mistapi.api.v1.orgs.setting.skyatp.setup.getOrgSkyAtpIntegration(# SDK call using URL-mirrored path
            self.apisession, org_id,                                                # apisession from class ctor
        )
        body = response.data or {}                                                  # normalize None to empty dict
        feeds = body.get("secintel", {}).get("third_party_threat_feeds", []) or []  # tolerate missing secintel key
        logging.debug(                                                              # after-API-call summary log (ASCII only)
            "Sky ATP: third_party_feed_count=%d has_allowlist_url=%s has_blocklist_url=%s",
            len(feeds), bool(body.get("secintel_allowlist_url")),                   # boolean flag, no signed URL echoed
            bool(body.get("secintel_blocklist_url")),                               # boolean flag, no signed URL echoed
        )

        logging.info("Flattening Sky ATP integration summary for org %s", org_id)   # before-flatten action log
        summary_row = self._flatten_sky_atp_summary(org_id, body, feeds)            # build one summary dict
        logging.debug("Flattened 1 summary row")                                    # after-flatten count log

        logging.info("Writing Sky ATP integration summary via DataExporter")        # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [summary_row],                                                          # list-of-rows interface
            filename=f"org_{org_id[:8]}_sky_atp_integration",                       # human-friendly stem
            api_function_name="getOrgSkyAtpIntegration",                            # PK strategy lookup key
        )

        logging.info("Flattening %d third-party threat feed rows", len(feeds))      # before-flatten action log
        feed_rows = self._flatten_sky_atp_feeds(org_id, feeds)                      # one row per feed name
        logging.debug("Flattened %d threat feed rows", len(feed_rows))              # after-flatten count log
        logging.info("Writing Sky ATP threat feeds via DataExporter")               # before-export action log
        DataExporter.write_with_format_selection(                                   # second multi-backend write
            feed_rows,                                                              # may be empty list when no feeds enabled
            filename=f"org_{org_id[:8]}_sky_atp_threat_feeds",                      # human-friendly stem
            api_function_name="getOrgSkyAtpIntegrationThreatFeeds",                 # MistHelper-internal sub-table key
        )
```

Helpers `_flatten_sky_atp_summary` and `_flatten_sky_atp_feeds` follow
the same comment- and log-density rules, stay under 25 lines each, and
live on the same `OrgSecuritySettingsUtils` class -- no standalone
wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py
python -m ruff check MistHelper.py
python -m black --check MistHelper.py
python MistHelper.py --test
```

Interpretation:

1. `py_compile` -- zero output means syntax is valid.
2. `ruff check` -- zero violations required.
3. `black --check` -- zero diffs required; rerun without `--check` to
   auto-fix formatting.
4. `--test` -- functional smoke test that includes menu 96. The sweep
   automatically skips heavy / destructive operations (14, 18, 63-65,
   90-100). Menu 96 sits inside the standard sweep range, so a green run
   confirms the new item works end to end against the org configured in
   `.env`.
