# Phase 1 Quickstart: getOrgStats

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-07-01

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this
file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`.
The API token is consumed by `mistapi.APISession` and is never written to logs
or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- Summary CSV: `data/org_<first-8-of-org-uuid>_stats_summary.csv`
- SLE CSV: `data/org_<first-8-of-org-uuid>_stats_sle.csv`
- SQLite: `data/mist_data.db`, tables `org_stats_summary` and `org_stats_sle`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline-comment and action-logging coverage
can be reviewed before the code is written. Every executable line carries a `#`
comment (Constitution VI), and every meaningful action is bracketed by
`logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class OrgExportUtils:                                                               # existing class at MistHelper.py:12165

    def export_org_stats(self, org_id=None, duration=None):                         # menu 58 entrypoint
        logging.info("Prompting for org_id for org-stats menu item")                # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_stats:org_id",                                             # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 58", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for stats window duration")                         # before-prompt action log
        duration = duration or safe_input(                                          # honor caller override else prompt user
            "Stats window (e.g. 1d, 7d, 2w) [1d]: ",                                # human-readable prompt text
            context="org_stats:duration",                                           # SSH/container EOF context tag
            default="1d",                                                           # matches Mist API default
        ) or "1d"                                                                   # empty answer -> API default

        logging.info("Fetching org stats for org %s window %s", org_id, duration)   # before-API-call action log
        response = mistapi.api.v1.orgs.stats.getOrgStats(                           # actual SDK call
            self.apisession, org_id, duration=duration,                             # only pass the window we care about
        )
        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug(                                                              # after-API-call summary log
            "Org stats: sites=%s devices=%s connected=%s disconnected=%s",
            body.get("num_sites"), body.get("num_devices"),
            body.get("num_devices_connected"), body.get("num_devices_disconnected"),
        )

        polled_at_utc = datetime.datetime.now(datetime.timezone.utc).isoformat()    # stable poll timestamp for composite PK
        logging.info("Flattening org stats summary for org %s", org_id)             # before-flatten action log
        summary_row = self._flatten_org_stats_summary(body, polled_at_utc)          # build one summary dict
        logging.debug("Flattened 1 summary row")                                    # after-flatten count log

        logging.info("Flattening SLE rows")                                         # before-flatten action log
        sle_rows = self._flatten_org_stats_sle(org_id, body, polled_at_utc)         # one row per SLE path
        logging.debug("Flattened %d SLE rows", len(sle_rows))                       # after-flatten count log

        logging.info("Writing org stats summary via DataExporter")                  # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [summary_row],                                                          # list-of-rows interface
            filename=f"org_{org_id[:8]}_stats_summary",                             # human-friendly stem
            api_function_name="getOrgStats",                                        # PK strategy lookup key
        )
        if sle_rows:                                                                # only write SLE file when non-empty
            logging.info("Writing org stats SLE via DataExporter")                  # before-export action log
            DataExporter.write_with_format_selection(                               # second multi-backend write
                sle_rows,                                                           # list of SLE dicts
                filename=f"org_{org_id[:8]}_stats_sle",                             # human-friendly stem
                api_function_name="getOrgStatsSleRows",                             # MistHelper-internal sub-table key
            )
```

Helpers `_flatten_org_stats_summary` and `_flatten_org_stats_sle` follow the
same comment- and log-density rules, stay under 25 lines, and live on the same
`OrgExportUtils` class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 58 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 58 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the org configured in `.env`.
