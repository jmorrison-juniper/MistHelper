# Phase 1 Quickstart: countSiteSystemEvents

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new menu
item on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_SITE_ID=<your-default-site-uuid>   # optional default for the site_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- CSV: `data/site_<first-8-of-site-uuid>_system_events_count_<distinct>_<window>.csv`
  (e.g., `data/site_0a1b2c3d_system_events_count_type_1d.csv`)
- SQLite: `data/mist_data.db`, table `site_system_events_count`
- ArangoDB / Redis: same collection / key namespace
  (`site_system_events_count`) when the polyglot backend is selected.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before the code is written. Every executable line carries a `#` comment (Constitution
VI), and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class SiteEventsExportUtils:                                                        # existing class hosting sibling site-events ops

    def export_site_system_events_count(                                            # menu 89 entrypoint
        self,
        site_id=None,                                                               # optional override; else prompt
        distinct="type",                                                            # default bucket attribute
        event_type=None,                                                            # optional Mist event_type filter
        time_window="1d",                                                           # default duration shorthand
    ):
        logging.info("Prompting for site_id for system-events count menu item")     # before-prompt action log
        site_id = site_id or safe_input(                                            # honor caller override else prompt
            "Site ID (UUID): ",                                                     # human-readable prompt
            context="site_system_events_count:site_id",                             # SSH/container EOF context tag
            default=os.environ.get("MIST_SITE_ID", ""),                             # optional .env default
        )
        if not is_valid_uuid(site_id):                                              # validate before any API call
            logging.warning("Invalid site_id %s -- aborting menu 89", site_id)      # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for distinct attribute / type filter / window")     # before-prompt action log
        distinct = safe_input(                                                      # bucket-by attribute prompt
            "Distinct attribute (e.g., type, device_type, model) [type]: ",
            context="site_system_events_count:distinct",
            default="type",
        ) or "type"                                                                 # normalize blank to default
        event_type = safe_input(                                                    # optional event_type filter prompt
            "Filter by event type (blank for all): ",
            context="site_system_events_count:type",
            default="",
        ).strip() or None                                                           # empty -> omit query param
        time_window = safe_input(                                                   # duration prompt
            "Time window (e.g., 1d, 7d, 2w) [1d]: ",
            context="site_system_events_count:duration",
            default="1d",
        ) or "1d"                                                                   # normalize blank to default

        logging.info(                                                               # before-API-call action log
            "Counting system events for site %s distinct=%s window=%s",
            site_id, distinct, time_window,
        )
        response = mistapi.api.v1.sites.events.system.count.countSiteSystemEvents(  # actual SDK call
            self.apisession,                                                        # authenticated mistapi session
            site_id,                                                                # path param
            distinct=distinct,                                                      # bucket attribute
            type=event_type,                                                        # None -> omitted by SDK
            duration=time_window,                                                   # default 1d when blank
        )
        body = response.data or {}                                                  # normalize None to empty dict
        buckets = body.get("results") or []                                         # bucket array; empty when no events
        logging.debug(                                                              # after-API-call summary log
            "Returned %d buckets totalling %d events",
            len(buckets), body.get("total", 0),
        )

        logging.info("Flattening %d buckets for site %s", len(buckets), site_id)    # before-flatten action log
        rows = self._flatten_count_buckets(site_id, body)                           # list[dict] -- one row per bucket
        logging.debug("Flattened %d rows", len(rows))                               # after-flatten count log

        logging.info("Writing site system event counts via DataExporter")           # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            rows,                                                                   # may be empty -- DataExporter handles
            filename=(                                                              # deterministic stem
                f"site_{site_id[:8]}_system_events_count_"
                f"{distinct}_{time_window}"
            ),
            api_function_name="countSiteSystemEvents",                              # PK strategy lookup key
        )
```

The helper `_flatten_count_buckets` follows the same comment- and log-density rules,
stays under 25 lines, and lives on the same `SiteEventsExportUtils` class -- no
standalone wrapper function. Its job: for each bucket in `body['results']`, build a
dict with `site_id`, `distinct_attribute = body['distinct']`, `window_start =
body['start']`, `window_end = body['end']`, `distinct_value =
bucket.pop(body['distinct'], '')`, `count = bucket.pop('count')`, `limit_applied =
body.get('limit')`, `window_total = body.get('total')`, `bucket_extra_json =
json.dumps(bucket)` (whatever string properties remain), and `polled_at_utc =
datetime.now(timezone.utc).isoformat()`.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 89 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 89 sits inside the standard sweep range, so a green run confirms the
new item works end to end against the site configured in `.env`.
