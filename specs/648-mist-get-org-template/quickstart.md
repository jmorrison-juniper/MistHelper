# Phase 1 Quickstart: GetOrgTemplate

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-07-01

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>          # optional default for prompt 1
MIST_TEMPLATE_ID=<your-default-template-uuid># optional default for prompt 2 (rare)
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; on Linux
containers run `chmod -R 777 data/` once before first container run to satisfy
the non-root container user).

- Parent CSV: `data/org_<first-8-of-org-uuid>_wlan_template_<first-8-of-tpl-uuid>.csv`
- Scopes CSV: `data/org_<first-8-of-org-uuid>_wlan_template_<first-8-of-tpl-uuid>_scopes.csv`
- SQLite: `data/mist_data.db`, tables `org_wlan_templates` and
  `org_wlan_template_scopes`.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class WLANTemplateExportUtils:                                                    # existing class, no new wrapper

    def export_org_wlan_template_detail(self, org_id=None, template_id=None):     # menu 58 entrypoint
        logging.info("Prompting for org_id for WLAN template detail menu item")   # before-prompt action log
        org_id = org_id or safe_input(                                            # honor caller override else prompt user
            "Org ID (UUID): ",                                                    # human-readable prompt text
            context="org_template_detail:org_id",                                 # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                            # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                             # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 58", org_id)      # log validation failure (no traceback)
            return                                                                # early return per safety-first principle

        logging.info("Prompting for template_id for WLAN template detail menu")   # before-prompt action log
        template_id = template_id or safe_input(                                  # honor caller override else prompt user
            "WLAN Template ID (UUID): ",                                          # human-readable prompt text
            context="org_template_detail:template_id",                            # EOF context tag
            default=os.environ.get("MIST_TEMPLATE_ID", ""),                       # fall back to .env default
        )
        if not is_valid_uuid(template_id):                                        # validate before any API call
            logging.warning("Invalid template_id %s -- aborting menu 58", template_id)  # log validation failure
            return                                                                # early return per safety-first principle

        logging.info("Fetching WLAN template %s in org %s", template_id[:8], org_id[:8])  # before-API-call action log
        response = mistapi.api.v1.orgs.wlan_templates.getOrgTemplate(             # actual SDK call
            self.apisession, org_id, template_id,                                 # positional path params per SDK signature
        )
        body = response.data or {}                                                # normalize None to empty dict
        logging.debug(                                                            # after-API-call summary log
            "Template name=%s deviceprofile_count=%s apply_scope_count=%s",       # ASCII-only summary
            body.get("name"),                                                     # required field per schema
            len(body.get("deviceprofile_ids") or []),                             # tolerant of missing / None
            len((body.get("applies") or {}).get("site_ids") or []),               # count of applies sites
        )

        logging.info("Flattening WLAN template parent row")                       # before-flatten action log
        parent_row = self._flatten_wlan_template_parent(org_id, body)             # build one summary dict
        logging.debug("Flattened 1 parent row")                                   # after-flatten count log

        logging.info("Flattening WLAN template scope rows")                       # before-flatten action log
        scope_rows = self._flatten_wlan_template_scopes(template_id, body)        # list of scope dicts
        logging.debug("Flattened %d scope rows", len(scope_rows))                 # after-flatten count log

        logging.info("Writing WLAN template parent via DataExporter")             # before-export action log
        DataExporter.write_with_format_selection(                                 # multi-backend write
            [parent_row],                                                         # list-of-rows interface
            filename=f"org_{org_id[:8]}_wlan_template_{template_id[:8]}",         # human-friendly stem
            api_function_name="getOrgTemplate",                                   # PK strategy lookup key
        )

        logging.info("Writing WLAN template scopes via DataExporter")             # before-export action log
        DataExporter.write_with_format_selection(                                 # second multi-backend write
            scope_rows,                                                           # may be empty list when no scopes
            filename=f"org_{org_id[:8]}_wlan_template_{template_id[:8]}_scopes",  # human-friendly stem
            api_function_name="getOrgTemplateScopes",                             # MistHelper-internal sub-table key
        )
```

Helpers `_flatten_wlan_template_parent` and `_flatten_wlan_template_scopes`
follow the same comment- and log-density rules, stay under 25 lines, and live
on the same `WLANTemplateExportUtils` class -- no standalone wrapper
functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 58 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 58 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the org / template configured
in `.env`.
