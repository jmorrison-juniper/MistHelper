# Phase 1 Quickstart: getMspSso

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token-with-msp-read-scope>
MIST_MSP_ID=<your-default-msp-uuid>   # optional default for the msp_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout. The token MUST have MSP-tier read scope; an
org-only token returns HTTP 403.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it
with `chmod -R 777 data/` on Linux first to satisfy the non-root container
user).

- CSV: `data/msp_<first-8-of-msp-uuid>_sso_<first-8-of-sso-uuid>.csv`
- SQLite: `data/mist_data.db`, table `msp_ssos` (shared across every menu 59
  invocation; primary key on `id` keeps it deduplicated).

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class MspExportUtils:                                                           # new class, MSP-scoped reads cluster

    def export_msp_sso(self, msp_id=None, sso_id=None):                         # menu 59 entrypoint, <=3 params
        logging.info("Prompting for msp_id for MSP SSO menu item")              # before-prompt action log
        msp_id = msp_id or safe_input(                                          # honor caller override else prompt user
            "MSP ID (UUID): ",                                                  # human-readable prompt text
            context="msp_sso:msp_id",                                           # SSH/container EOF context tag
            default=os.environ.get("MIST_MSP_ID", ""),                          # fall back to .env default
        )
        if not is_valid_uuid(msp_id):                                           # validate before any API call
            logging.warning("Invalid msp_id %s -- aborting menu 59", msp_id)    # log validation failure (no traceback)
            return                                                              # early return per safety-first principle

        logging.info("Prompting for sso_id for MSP SSO menu item")              # before-prompt action log
        sso_id = sso_id or safe_input(                                          # second prompt, no .env default
            "SSO ID (UUID): ",                                                  # prompt text
            context="msp_sso:sso_id",                                           # EOF context tag
        )
        if not is_valid_uuid(sso_id):                                           # validate before any API call
            logging.warning("Invalid sso_id %s -- aborting menu 59", sso_id)    # log validation failure
            return                                                              # early return

        logging.info("Fetching SSO %s for MSP %s", sso_id, msp_id)              # before-API-call action log
        response = mistapi.api.v1.msps.ssos.getMspSso(                          # actual SDK call
            self.apisession, msp_id, sso_id,                                    # two path params, no query
        )
        body = response.data or {}                                              # normalize None to empty dict
        logging.debug(                                                          # after-API-call summary log (no secrets)
            "SSO retrieved: id=%s name=%s idp_type=%s",                         # only non-sensitive identifying fields
            body.get("id"), body.get("name"), body.get("idp_type"),
        )

        logging.info("Flattening SSO record for SQLite/CSV/ArangoDB")           # before-flatten action log
        sso_row = self._flatten_msp_sso(body)                                   # build one row dict
        logging.debug("Flattened 1 SSO row")                                    # after-flatten count log

        logging.info("Writing MSP SSO via DataExporter")                        # before-export action log
        DataExporter.write_with_format_selection(                               # multi-backend write
            [sso_row],                                                          # list-of-rows interface
            filename=f"msp_{msp_id[:8]}_sso_{sso_id[:8]}",                      # human-friendly stem
            api_function_name="getMspSso",                                      # PK strategy lookup key
        )
```

The private helper `_flatten_msp_sso(body)` lives on the same `MspExportUtils`
class, stays under 25 lines, takes one parameter, and serializes the nested
`mxedge_proxy`, `openroaming`, `ldap_cacerts`, and `ldap_server_hosts` sub-
structures to JSON strings before assembling the flat row dict per the
`data-model.md` schema. No standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 59 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 59 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the MSP/SSO configured in
`.env`.
