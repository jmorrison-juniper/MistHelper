# Phase 1 Quickstart: getOrgPskPortal

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new menu
item on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this
file. The API token is consumed by `mistapi.APISession` and is never written to
logs or stdout.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>          # optional default for prompt 1
MIST_PSK_PORTAL_ID=<your-default-portal-uuid># optional default for prompt 2
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`.
The two "default" values are optional but strongly recommended for scripted /
`--test` runs.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; on Linux run
`chmod -R 777 data/` before the first container run so the non-root
`misthelper` user can write there).

- CSV: `data/org_<first-8-of-org-uuid>_psk_portal_<first-8-of-portal-uuid>.csv`
- SQLite: `data/mist_data.db`, table `org_psk_portals` (PK = `id`)
- ArangoDB (if the polyglot backend is active): collection `org_psk_portals`,
  document `_key = <portal uuid>`
- Redis (if the polyglot backend is active): cache keys namespaced under
  `mist:org_psk_portals:<portal uuid>`

Only one file per invocation -- the endpoint returns exactly one JSON object.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline-comment and action-logging coverage
can be reviewed *before* the code is written. Every executable line carries a
`#` comment (Constitution VI), and every meaningful action is bracketed by
`logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class WLANExportUtils:                                                              # existing class hosting PSK/WLAN exports

    def export_org_psk_portal(self, org_id=None, pskportal_id=None):                # menu 89 entrypoint
        logging.info("Prompting for org_id for PSK portal menu item")               # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_psk_portal:org_id",                                        # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before wasting an API call
            logging.warning("Invalid org_id %s -- aborting menu 89", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per Safety-First principle

        logging.info("Prompting for pskportal_id")                                  # before-prompt action log
        pskportal_id = pskportal_id or safe_input(                                  # honor caller override else prompt user
            "PSK Portal ID (UUID): ",                                               # human-readable prompt text
            context="org_psk_portal:pskportal_id",                                  # SSH/container EOF context tag
            default=os.environ.get("MIST_PSK_PORTAL_ID", ""),                       # fall back to .env default
        )
        if not is_valid_uuid(pskportal_id):                                         # validate second UUID before API call
            logging.warning("Invalid pskportal_id %s -- aborting", pskportal_id)    # log validation failure (no traceback)
            return                                                                  # early return per Safety-First principle

        logging.info("Fetching PSK portal %s for org %s",                           # before-API-call action log
                     pskportal_id[:8], org_id[:8])                                  # log only short-UUID prefixes
        response = mistapi.api.v1.orgs.psk_portals.getOrgPskPortal(                 # SDK call, one HTTP GET
            self.apisession, org_id, pskportal_id,                                  # both path parameters
        )
        body = response.data or {}                                                  # normalize None body to empty dict
        logging.debug(                                                              # after-API-call summary log
            "Received PSK portal: name=%s ssid=%s type=%s",
            body.get("name"), body.get("ssid"), body.get("type"),
        )

        logging.info("Flattening PSK portal payload for %s", pskportal_id[:8])      # before-flatten action log
        row = self._flatten_psk_portal_row(org_id, body)                            # build one flat dict row
        logging.debug("Flattened 1 row")                                            # after-flatten count log

        logging.info("Writing PSK portal via DataExporter")                         # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [row],                                                                  # list-of-rows interface (single element)
            filename=f"org_{org_id[:8]}_psk_portal_{pskportal_id[:8]}",             # human-friendly filename stem
            api_function_name="getOrgPskPortal",                                    # PK strategy lookup key
        )
```

The `_flatten_psk_portal_row` helper follows the same comment- and log-density
rules, stays under 25 lines, and lives on the same class -- no standalone
wrapper functions (Constitution Principle II). It uses the existing
`flatten_dict()` helper with prefixes `passphrase_rules_` and `sso_` for the two
nested objects, and `json.dumps` for the three list/dict-shaped fields
(`required_fields`, `vlan_id`, `sso.allowed_roles`, `sso.role_mapping`) that are
stored as JSON columns.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; drop --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 89 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100, 154-194). Menu 89 sits inside the standard sweep range, so a
green run confirms the new item works end-to-end against the org and portal
configured in `.env`.
