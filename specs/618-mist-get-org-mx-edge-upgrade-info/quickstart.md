# Phase 1 Quickstart: getOrgMxEdgeUpgradeInfo

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on the Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this
file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- CSV: `data/org_<first-8-of-org-uuid>_mxedge_upgrade_info.csv`
- SQLite: `data/mist_data.db`, table `org_mxedge_upgrade_info`
- ArangoDB collection (when ArangoDB+Redis backend is active):
  `org_mxedge_upgrade_info`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging coverage
can be reviewed before the code is written. Every executable line carries a `#`
comment (Constitution VI), and every meaningful action is bracketed by
`logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class FirmwareManager:                                                              # existing class, no new wrapper

    def export_org_mxedge_upgrade_info(                                             # menu 59 entrypoint
        self,
        org_id=None,                                                                # caller override; else prompt
        channel=None,                                                               # caller override; else prompt
        distro=None,                                                                # caller override; else prompt
    ):
        logging.info("Prompting for org_id for Mist Edge upgrade info menu item")   # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_mxedge_upgrade_info:org_id",                               # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 59", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for upgrade channel")                               # before-prompt action log
        channel_choice = (channel or safe_input(                                    # accept caller value or prompt user
            "Upgrade channel (stable / beta / alpha) [stable]: ",                   # default shown inline
            context="org_mxedge_upgrade_info:channel",                              # EOF context tag
            default="stable",                                                       # explicit default for non-interactive runs
        )).strip().lower() or "stable"                                              # normalize empty string to default

        logging.info("Prompting for distro filter")                                 # before-prompt action log
        distro_filter = (distro if distro is not None else safe_input(              # accept caller value or prompt user
            "Distro filter (e.g. bullseye, buster) [all]: ",                        # empty answer = no filter
            context="org_mxedge_upgrade_info:distro",                               # EOF context tag
            default="",                                                             # default is no filter
        )).strip()                                                                  # trim whitespace from user input

        logging.info(                                                               # before-API-call action log
            "Fetching Mist Edge upgrade info for org %s (channel=%s distro=%s)",
            org_id, channel_choice, distro_filter or "all",
        )
        response = mistapi.api.v1.orgs.mxedges.versions.getOrgMxEdgeUpgradeInfo(    # actual SDK call
            self.apisession,                                                        # authenticated session from constructor
            org_id,                                                                 # path parameter
            channel=channel_choice,                                                 # query parameter
            distro=(distro_filter or None),                                         # omit query param when empty
        )
        rows = response.data or []                                                  # normalize None to empty list
        logging.debug("Received %d firmware packages", len(rows))                   # after-API-call summary log

        logging.info("Flattening %d upgrade rows for org %s", len(rows), org_id)    # before-flatten action log
        flat_rows = self._flatten_mxedge_upgrade_rows(                              # one row per package/version
            org_id, channel_choice, distro_filter, rows,
        )
        logging.debug("Flattened %d rows ready for export", len(flat_rows))         # after-flatten count log

        logging.info("Writing Mist Edge upgrade info via DataExporter")             # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            flat_rows,                                                              # list-of-rows interface
            filename=f"org_{org_id[:8]}_mxedge_upgrade_info",                       # human-friendly stem
            api_function_name="getOrgMxEdgeUpgradeInfo",                            # PK strategy lookup key
        )
```

The helper `_flatten_mxedge_upgrade_rows()` follows the same comment- and
log-density rules, stays under 25 lines, and lives on the same
`FirmwareManager` class -- no standalone wrapper functions. It injects
`org_id`, `channel`, `polled_at_utc`, and `distro_filter` onto each API row,
substitutes the `_unspecified_` sentinel when an API row omits `distro`, and
normalizes the boolean `default` to integer `0` / `1` for SQLite portability.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 59 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 59 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the org configured in `.env`.
