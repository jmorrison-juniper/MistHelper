# Phase 1 Quickstart: getOrgWxTunnel

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-07-01

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on the Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>       # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- Parent CSV: `data/org_<first-8-of-org-uuid>_wxtunnel_<first-8-of-wxtunnel-uuid>.csv`
- Sessions CSV:
  `data/org_<first-8-of-org-uuid>_wxtunnel_<first-8-of-wxtunnel-uuid>_sessions.csv`
  (emitted whenever the response includes a non-empty `sessions[]` array; the file is
  created with header-only when the array is empty so downstream consumers see a
  consistent schema)
- SQLite: `data/mist_data.db`, tables `org_wxtunnels` and `org_wxtunnel_sessions`

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before the code is written. Every executable line carries a `#` comment (Constitution
VI), and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class TemplateExportUtils:                                                          # existing class, no new wrapper

    def export_org_wx_tunnel(self, org_id=None, wxtunnel_id=None):                  # menu 59 entrypoint
        logging.info("Prompting for org_id for WxTunnel menu item")                 # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_wx_tunnel:org_id",                                         # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 59", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for wxtunnel_id")                                   # before-prompt action log
        wxtunnel_id = wxtunnel_id or safe_input(                                    # honor caller override else prompt user
            "WxTunnel ID (UUID): ",                                                 # human-readable prompt text
            context="org_wx_tunnel:wxtunnel_id",                                    # SSH/container EOF context tag
        )
        if not is_valid_uuid(wxtunnel_id):                                          # validate before any API call
            logging.warning("Invalid wxtunnel_id %s -- aborting", wxtunnel_id)      # log validation failure
            return                                                                  # early return per safety-first principle

        logging.info("Fetching WxTunnel %s for org %s", wxtunnel_id, org_id)        # before-API-call action log
        response = mistapi.api.v1.orgs.wxtunnels.getOrgWxTunnel(                    # actual SDK call
            self.apisession, org_id, wxtunnel_id,                                   # positional path parameters
        )
        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug(                                                              # after-API-call redacted summary log
            "WxTunnel name=%s use_udp=%s sessions=%d dmvpn=%s ipsec_enabled=%s psk=<redacted>",
            body.get("name"),                                                       # human-readable identifier
            body.get("use_udp"),                                                    # transport flag
            len(body.get("sessions") or []),                                        # session count
            (body.get("dmvpn") or {}).get("enabled"),                               # dmvpn state
            (body.get("ipsec") or {}).get("enabled"),                               # ipsec state (psk itself never logged)
        )

        logging.info("Flattening parent WxTunnel row")                              # before-flatten action log
        parent_row = self._flatten_wxtunnel_row(org_id, body)                       # build one parent dict (psk kept, secret kept)
        logging.debug("Flattened 1 parent row")                                     # after-flatten count log

        logging.info("Flattening %d session rows", len(body.get("sessions") or [])) # before-flatten action log
        session_rows = self._flatten_wxtunnel_sessions(wxtunnel_id, body)           # zero-or-more session dicts
        logging.debug("Flattened %d session rows", len(session_rows))               # after-flatten count log

        logging.info("Writing WxTunnel parent row via DataExporter")                # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [parent_row],                                                           # list-of-rows interface
            filename=f"org_{org_id[:8]}_wxtunnel_{wxtunnel_id[:8]}",                # human-friendly stem
            api_function_name="getOrgWxTunnel",                                     # PK strategy lookup key
        )

        logging.info("Writing WxTunnel sessions via DataExporter")                  # before-export action log
        DataExporter.write_with_format_selection(                                   # second multi-backend write
            session_rows,                                                           # may be empty list
            filename=f"org_{org_id[:8]}_wxtunnel_{wxtunnel_id[:8]}_sessions",       # human-friendly stem
            api_function_name="getOrgWxTunnelSessions",                             # MistHelper-internal sub-table key
        )
```

Helpers `_flatten_wxtunnel_row` and `_flatten_wxtunnel_sessions` follow the same
comment- and log-density rules, stay under 25 lines and 5 blocks each, and live on the
same `TemplateExportUtils` class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 59 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 59 sits inside the standard sweep range, so a green run confirms the
new item works end to end against the org and tunnel configured in `.env` fixtures.
