# Phase 1 Quickstart: getOrgSamlMetadata

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new menu
item on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
MIST_SSO_ID=<your-default-sso-uuid>   # optional default for the sso_id prompt (new)
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`.
The API token is consumed by `mistapi.APISession` and is never written to logs or
stdout. To discover valid `sso_id` values, run the existing `listOrgSsos` menu
item first.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- CSV: `data/org_<first-8-of-org-uuid>_sso_<first-8-of-sso-uuid>_saml_metadata.csv`
- SQLite: `data/mist_data.db`, table `org_sso_saml_metadata`
- ArangoDB / Redis: collection `org_sso_saml_metadata` / key namespace
  `org_sso_saml_metadata:<org_id>:<sso_id>` (handled by `DataExporter` without any
  menu-item-specific code).

Because the `metadata` column contains multi-line XML, the CSV emitter uses
`csv.QUOTE_ALL` quoting so the row survives parse in Excel, LibreOffice, or the
Python `csv` module.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging coverage
can be reviewed before the code is written. Every executable line carries a `#`
comment (Constitution VI), and every meaningful action is bracketed by
`logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class ConfigAdminExportUtils:                                                       # existing class, no new wrapper

    def export_org_saml_metadata(self, org_id=None, sso_id=None):                   # menu 58 entrypoint
        logging.info("Prompting for org_id for SAML metadata menu item")            # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_saml_metadata:org_id",                                     # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 58", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for sso_id for SAML metadata menu item")            # before-prompt action log
        sso_id = sso_id or safe_input(                                              # honor caller override else prompt user
            "SSO ID (UUID): ",                                                      # human-readable prompt text
            context="org_saml_metadata:sso_id",                                     # SSH/container EOF context tag
            default=os.environ.get("MIST_SSO_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(sso_id):                                               # validate before any API call
            logging.warning("Invalid sso_id %s -- aborting menu 58", sso_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Fetching SAML metadata for org %s sso %s", org_id, sso_id)    # before-API-call action log
        response = mistapi.api.v1.orgs.ssos.metadata.getOrgSamlMetadata(            # actual SDK call
            self.apisession, org_id, sso_id,                                        # positional path params
        )
        body = response.data or {}                                                  # normalize None to empty dict
        raw_metadata = body.get("metadata") or ""                                   # empty string preserves length math
        logging.debug(                                                              # after-API-call summary log
            "SAML metadata: entity_id=%s metadata_bytes=%d has_scim=%s",
            body.get("entity_id"), len(raw_metadata), bool(body.get("scim_base_url")),
        )

        logging.info("Flattening SAML metadata payload")                            # before-flatten action log
        metadata_row = self._flatten_saml_metadata(org_id, sso_id, body)            # build one flat dict
        logging.debug("Flattened 1 metadata row")                                   # after-flatten count log

        logging.info("Writing SAML metadata via DataExporter")                      # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [metadata_row],                                                         # list-of-rows interface
            filename=f"org_{org_id[:8]}_sso_{sso_id[:8]}_saml_metadata",            # human-friendly stem
            api_function_name="getOrgSamlMetadata",                                 # PK strategy lookup key
        )
```

The helper `_flatten_saml_metadata` follows the same comment- and log-density
rules, stays under 25 lines, and lives on the same class -- no standalone wrapper
functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 58 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 58 sits inside the standard sweep range, so a green run confirms the
new item works end to end against the org / SSO configured in `.env`.
