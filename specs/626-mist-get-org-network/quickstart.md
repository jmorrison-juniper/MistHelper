# Phase 1 Quickstart: getOrgNetwork

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Discovering a Network UUID for the second prompt

The by-ID endpoint requires a specific `network_id` UUID. There is no `.env` default
for this value. To obtain one for testing:

```powershell
python MistHelper.py --menu 4     # runs listOrgNetworks; writes CSV / SQLite under data/
```

Then open `data/OrgNetworks.csv` (or query `SELECT id, name FROM org_network` against
`data/mist_data.db`) and copy the `id` field of the network you want to inspect.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; run
`chmod -R 777 data/` on Linux first so the non-root container user can write).

- Parent CSV:
  `data/org_<first-8-of-org-uuid>_network_<first-8-of-network-uuid>.csv`
- Child CSVs (only emitted when the corresponding map has at least one entry):
  - `..._network_<short>_destination_nat.csv`
  - `..._network_<short>_static_nat.csv`
  - `..._network_<short>_multicast_groups.csv`
  - `..._network_<short>_tenants.csv`
  - `..._network_<short>_vpn_access.csv`
- SQLite: `data/mist_data.db`, tables `org_network`, `org_network_destination_nat`,
  `org_network_static_nat`, `org_network_multicast_groups`, `org_network_tenants`,
  `org_network_vpn_access`.

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so inline-comment and action-logging coverage can be reviewed before
the code is written. Every executable line carries a `#` comment (Constitution VI), and
every meaningful action is bracketed by `logging.info()` / `logging.debug()` calls
(Constitution VII).

```python
class OrgNetworksExport:                                                            # existing class owning listOrgNetworks

    def export_org_network(self, org_id=None, network_id=None):                     # menu 58 entrypoint
        logging.info("Prompting for org_id for getOrgNetwork menu item")            # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_network:org_id",                                           # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 58", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for network_id")                                    # before-prompt action log
        network_id = network_id or safe_input(                                      # honor caller override else prompt user
            "Network ID (UUID -- run menu 4 first if you need to look this up): ", # explicit hint on where to find it
            context="org_network:network_id",                                       # EOF context tag
            default="",                                                             # no .env default for network_id
        )
        if not is_valid_uuid(network_id):                                           # validate before any API call
            logging.warning("Invalid network_id %s -- aborting menu 58", network_id) # log validation failure
            return                                                                  # early return per safety-first principle

        logging.info("Fetching network %s for org %s", network_id, org_id)          # before-API-call action log
        response = mistapi.api.v1.orgs.networks.getOrgNetwork(                      # actual SDK call
            self.apisession, org_id, network_id,                                    # required path params only
        )
        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug(                                                              # after-API-call summary log
            "Network name=%s subnet=%s vlan_id=%s tenants=%d",
            body.get("name"), body.get("subnet"), body.get("vlan_id"),
            len(body.get("tenants") or {}),
        )

        logging.info("Flattening network payload for network %s", network_id)       # before-flatten action log
        parent_row, child_map_rows = self._flatten_org_network(org_id, body)        # returns dict + dict-of-list-of-dicts
        logging.debug(                                                              # after-flatten count log
            "Flattened 1 parent row, %d destination_nat, %d static_nat, "
            "%d multicast_groups, %d tenants, %d vpn_access",
            len(child_map_rows["destination_nat"]), len(child_map_rows["static_nat"]),
            len(child_map_rows["multicast_groups"]), len(child_map_rows["tenants"]),
            len(child_map_rows["vpn_access"]),
        )

        logging.info("Writing network parent via DataExporter")                     # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write for parent
            [parent_row],                                                           # list-of-rows interface
            filename=f"org_{org_id[:8]}_network_{network_id[:8]}",                  # human-friendly stem
            api_function_name="getOrgNetwork",                                      # PK strategy lookup key
        )

        self._write_child_map("destination_nat", child_map_rows, org_id, network_id) # emit child NAT table
        self._write_child_map("static_nat", child_map_rows, org_id, network_id)      # emit child static NAT table
        self._write_child_map("multicast_groups", child_map_rows, org_id, network_id) # emit multicast groups
        self._write_child_map("tenants", child_map_rows, org_id, network_id)         # emit tenants
        self._write_child_map("vpn_access", child_map_rows, org_id, network_id)      # emit VPN access rows
```

`_flatten_org_network` and `_write_child_map` follow the same comment- and log-density
rules, stay under 25 lines each, and live as private methods on the same class -- no
standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 58 included)
```

The `--test` sweep automatically skips heavy / destructive operations (14, 18, 63-65,
90-100). Menu 58 sits inside the standard sweep range, so a green run confirms the new
item works end to end against the org / network configured in `.env`.
