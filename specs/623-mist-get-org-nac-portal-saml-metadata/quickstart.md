# Phase 1 Quickstart: GetOrgNacPortalSamlMetadata

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-30

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>       # optional default for the org_id prompt
# No MIST_NACPORTAL_ID default -- the nacportal_id prompt has no default.
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; on Linux
create it with `chmod -R 777 data/` first to satisfy the non-root container
user).

- CSV: `data/org_<first-8-of-org-uuid>_nacportal_<first-8-of-portal-uuid>_saml_metadata.csv`
- SQLite: `data/mist_data.db`, table `org_nac_portal_saml_metadata`
- ArangoDB (when the polyglot backend is active): collection
  `org_nac_portal_saml_metadata`, document `_key` = `<org_id>_<nacportal_id>`

## Discover a `nacportal_id` first

The SAML metadata endpoint is per-portal, so an operator typically runs the
bulk list first to grab the UUID:

```powershell
python MistHelper.py --menu <bulk-list-menu>
# Read data/OrgNacPortals.csv and pick the `id` of the target portal.
```

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class OrgExportUtils:                                                               # existing class; no new wrapper

    def export_org_nac_portal_saml_metadata(self, org_id=None, nacportal_id=None):  # menu 89 entrypoint
        logging.info("Prompting for org_id for NAC portal SAML metadata menu item")  # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_nac_portal_saml:org_id",                                   # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 89", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for nacportal_id")                                  # before-prompt action log
        nacportal_id = nacportal_id or safe_input(                                  # honor caller override else prompt user
            "NAC Portal ID (UUID): ",                                               # prompt text
            context="org_nac_portal_saml:nacportal_id",                             # EOF context tag
        )
        if not is_valid_uuid(nacportal_id):                                         # validate before any API call
            logging.warning("Invalid nacportal_id %s -- aborting menu 89", nacportal_id)  # log validation failure
            return                                                                  # early return per safety-first principle

        logging.info(                                                               # before-API-call action log
            "Fetching SAML metadata for NAC portal %s in org %s",                   # ASCII-only formatting
            nacportal_id, org_id,                                                   # args (no secrets)
        )
        response = mistapi.api.v1.orgs.nacportals.saml_metadata.getOrgNacPortalSamlMetadata(  # SDK call
            self.apisession, org_id, nacportal_id,                                  # both required path params
        )
        body = response.data or {}                                                  # normalize None to empty dict

        logging.debug(                                                              # after-API-call summary log
            "SAML metadata: acs_url=%s entity_id=%s metadata_len=%d",               # length only; never echo the XML itself
            body.get("acs_url"), body.get("entity_id"), len(body.get("metadata") or ""),
        )

        logging.info("Flattening SAML metadata payload")                            # before-flatten action log
        portal_row = self._flatten_nac_portal_saml_metadata(org_id, nacportal_id, body)  # build one row
        logging.debug("Flattened 1 metadata row (idp_flavor=%s)",                   # after-flatten count/flavor log
                      portal_row.get("idp_flavor"))

        logging.info("Writing NAC portal SAML metadata via DataExporter")           # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [portal_row],                                                           # list-of-rows interface (always one row)
            filename=f"org_{org_id[:8]}_nacportal_{nacportal_id[:8]}_saml_metadata",  # human-friendly stem
            api_function_name="getOrgNacPortalSamlMetadata",                        # PK strategy lookup key
        )
```

The `_flatten_nac_portal_saml_metadata` helper follows the same comment- and
log-density rules, stays under 25 lines, and lives on the same
`OrgExportUtils` class -- no standalone wrapper functions.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 89 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 89 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the org configured in `.env`.
Because the test sweep does not know which NAC portal to target, provide a
`MIST_TEST_NACPORTAL_ID` env var (or accept that this menu is skipped when
the id is not defined; the smoke path in `--test` logs a WARNING and returns
cleanly per the safety-first principle).
