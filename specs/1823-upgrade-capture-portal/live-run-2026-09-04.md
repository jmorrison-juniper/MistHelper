## The four warnings

The walk chose `No, hold the reboot for a later manual window`, because two of
the four warnings appear only for that choice. The confirm page then drew all
four.

1. `One device already runs the version that you chose. The portal still sends
   the upgrade.`
2. `The selection holds more than one version, so the portal sends one call for
   each version.`
3. `The cloud reboots each of the 6 access point(s) of this run on its own. The
   reboot control reaches a switch and a gateway only.`
4. `A switch may reboot even with the reboot control off. Plan a window for every
   switch of this run.`

points at this site. Warning 4 is the repair of issue #2007, which records the
