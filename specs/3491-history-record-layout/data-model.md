# Data Model: Compact history records

No stored record changes.
No field, primary key, source projection, schema, route context, or paging rule changes.

The presentation reads the existing run, operation, and audit values.
Titles retain those values without a transform.
Existing moment titles retain their original stored text.
The Captures table remains unchanged.

Browser evidence records painted dimensions, text dimensions, titles, colors, and visible column intersections.
This test evidence exists only in the owner's temporary or persistent local artifact directory.
It contains controlled records, not production data.
