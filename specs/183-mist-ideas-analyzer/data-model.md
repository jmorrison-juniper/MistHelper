# Data Model: Mist Ideas Analyzer

**Feature**: 183-mist-ideas-analyzer | **Date**: 2026-04-09

## Entities

### Idea (input, parsed from CSV)

| Field | Type | Source | Description |
| - | - | - | - |
| title | str | CSV column 0 | Original idea title from Mist Ideas portal |
| description | str | CSV column 1 | Full idea description text |
| comments | list[Comment] | CSV column 2 (JSON) | User comments parsed from JSON array |
| content_hash | str | Derived | SHA256 of normalized title+desc+comments; used as cache key |

### Comment (nested in Idea)

| Field | Type | Source | Description |
| - | - | - | - |
| author | str | JSON field | Comment author name |
| date | str | JSON field | Comment date string |
| text | str | JSON field | Comment body text |

### IdeaAnalysis (AI response, one per idea)

| Field | Type | Source | Description |
| - | - | - | - |
| classification | str (enum) | AI response | One of: REPORT_EXPORT, API_ENHANCEMENT, HYBRID, GUI_ONLY, HARDWARE_FEATURE, ALREADY_SUPPORTED, UNCLASSIFIED |
| confidence | str (enum) | AI response | high, medium, or low |
| themes | list[str] | AI response | Topic tags (e.g., "inventory", "firmware", "NAC") |
| rationale | str | AI response | AI's explanation of the classification decision |
| misthelper_enhancement | str or None | AI response | Suggested operation type and capability area (null if not applicable) |
| possible_duplicate_titles | list[str] | AI response | Titles of other ideas this might duplicate |
| is_foundational | bool | AI response | True if this idea enables other ideas (snowball chain root) |
| unlocks | list[str] | AI response | Titles of ideas this would unblock if implemented |
| ai_inspired_ideas | list[AiInspiredIdea] | AI response | Net-new ideas generated by the AI during analysis |

### AiInspiredIdea (nested in IdeaAnalysis)

| Field | Type | Source | Description |
| - | - | - | - |
| title | str | AI response | AI-generated feature title |
| description | str | AI response | AI's description of the feature |
| source_idea_title | str | AI response | Title of the customer idea that inspired this entry |
| rationale | str | AI response | Why neither Mist GUI nor MistHelper currently addresses this |

### IdeaCluster (output, after dedup merge)

| Field | Type | Source | Description |
| - | - | - | - |
| canonical_title | str | Chosen by dedup pass | Representative title for the cluster |
| merged_titles | list[str] | Dedup pass | All original titles merged into this cluster |
| demand_count | int | Derived | Number of distinct ideas merged (popularity signal) |
| classification | str (enum) | From primary idea's IdeaAnalysis | Cluster-level classification |
| confidence | str (enum) | From primary idea's IdeaAnalysis | Cluster-level confidence |
| themes | list[str] | Union of all merged ideas | Combined theme tags |
| rationale | str | From primary idea's IdeaAnalysis | Classification rationale |
| misthelper_enhancement | str or None | From primary idea | Enhancement suggestion |
| is_foundational | bool | From primary idea | Snowball chain root flag |
| unlocks | list[str] | Union of all merged ideas | Combined unlock targets |
| possible_duplicate_of | list[str] or None | Dedup pass (low confidence) | Cross-reference to other clusters that might be duplicates but were not merged |

### ThemeGroup (output, grouping clusters by theme)

| Field | Type | Source | Description |
| - | - | - | - |
| theme | str | Derived from IdeaAnalysis.themes | Theme name (e.g., "inventory", "NAC") |
| clusters | list[IdeaCluster] | Filtered | All clusters tagged with this theme |
| total_demand | int | Derived | Sum of demand_count across clusters |

### SnowballChain (output, dependency ordering)

| Field | Type | Source | Description |
| - | - | - | - |
| root | IdeaCluster | is_foundational=True | The foundational idea that enables others |
| dependents | list[IdeaCluster] | Matched by unlocks | Ideas that this root would unblock |

### ApiIndex (pre-built lookup from OpenAPI spec)

| Field | Type | Source | Description |
| - | - | - | - |
| tag | str | OpenAPI tags | API tag grouping (e.g., "Orgs Devices", "Sites Stats") |
| endpoints | list[EndpointSummary] | OpenAPI paths | Endpoints under this tag |

### EndpointSummary (nested in ApiIndex)

| Field | Type | Source | Description |
| - | - | - | - |
| path | str | OpenAPI | URL path (e.g., "/api/v1/orgs/{org_id}/devices") |
| method | str | OpenAPI | HTTP method (GET, POST, etc.) |
| summary | str | OpenAPI | One-line description of what the endpoint does |
| parameters | list[str] | OpenAPI | Key parameter names |

## Relationships

```text
Idea  --[1:1]--> IdeaAnalysis (via content_hash cache key)
IdeaAnalysis --[0:N]--> AiInspiredIdea (nested in response)
IdeaAnalysis --[N:1]--> IdeaCluster (dedup merge pass groups ideas into clusters)
IdeaCluster  --[N:M]--> ThemeGroup (a cluster can belong to multiple themes)
IdeaCluster  --[0:1]--> SnowballChain.root (if is_foundational=True)
IdeaCluster  --[0:N]--> SnowballChain.dependents (if another cluster's unlocks references it)
ApiIndex     --[injected into]--> AI prompt (endpoint summaries for feasibility grounding)
```

## State Transitions

```text
CSV Row --> Idea (parsed) --> IdeaAnalysis (AI classified, cached)
                                --> AiInspiredIdea (0 or more AI-generated ideas)
IdeaAnalysis[] --> Dedup Pass --> IdeaCluster[] (merged duplicates)
IdeaCluster[] --> Theme Grouping --> ThemeGroup[]
IdeaCluster[] --> Snowball Detection --> SnowballChain[]
All above --> ReportGenerator --> .md + .json + .csv output files
```

## Validation Rules

- Idea.title must be non-empty after whitespace stripping
- Idea.comments JSON parse failure: log warning, set to empty list (do not abort)
- IdeaAnalysis.classification must be one of the 7 enum values; reject and retry if not
- IdeaAnalysis.confidence must be one of: high, medium, low
- IdeaCluster.demand_count must be >= 1
- ApiIndex is generated once and cached; rebuild only with `--refresh-index` flag
