# Generated Label Contract

For every generated parameter, the visible label's `htmlFor` equals its sibling control's `id`.
The control has exactly one associated label.
This rule applies to selection, text, and number controls, including dependent and replacement controls.

Names, values, defaults, dependency behavior, answer order, and request payloads remain unchanged.
The repair changes no CSS class, grouping, or mobile layout.
The regression tests must not start an operation or contact Mist.
