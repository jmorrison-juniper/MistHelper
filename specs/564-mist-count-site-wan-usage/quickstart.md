# Phase 1 Quickstart: countSiteWanUsage

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new menu
item on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell inside the Podman container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_SITE_ID=<your-default-site-uuid>   # optional default for the site_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- CSV: `data/site_<first-8-of-site-uuid>_wan_usage_counts.csv`
- SQLite: `data/mist_data.db`, table `site_wan_usage_counts`
- ArangoDB: collection `site_wan_usage_counts` (when the polyglot backend is active)

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before code is written. Every executable line carries a `#` comment (Constitution VI),
and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class SiteStatsExportUtils:                                                         # existing class, no new wrapper

    ALLOWED_DISTINCT = (                                                            # closed set of valid distinct fields
        "mac", "peer_mac", "port_id", "peer_port_id",                               # from the OpenAPI doc
        "policy", "tenant", "path_type",                                            # remaining options the API supports
    )

    def export_site_wan_usage_counts(self, site_id=None,                            # menu 91 entrypoint
                                     distinct_field=None,
                                     duration=None):
        logging.info("Prompting for site_id for WAN usage count menu item")         # before-prompt action log
        site_id = site_id or safe_input(                                            # honor caller override else prompt user
            "Site ID (UUID): ",                                                     # human-readable prompt text
            context="site_wan_usage_count:site_id",                                 # SSH/container EOF context tag
            default=os.environ.get("MIST_SITE_ID", ""),                             # fall back to .env default
        )
        if not is_valid_uuid(site_id):                                              # validate before any API call
            logging.warning("Invalid site_id %s -- aborting menu 91", site_id)      # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Prompting for distinct grouping field")                       # before-prompt action log
        distinct_field = (distinct_field or safe_input(                             # caller override else prompt
            "Group by (mac / peer_mac / port_id / peer_port_id / policy / "
            "tenant / path_type) [mac]: ",
            context="site_wan_usage_count:distinct",                                # EOF context tag
            default="mac",                                                          # default to MAC grouping
        )).strip().lower()                                                          # normalize for the closed-set check
        if distinct_field not in self.ALLOWED_DISTINCT:                             # validate against known fields
            logging.warning("Unknown distinct=%s -- defaulting to mac",             # ASCII warning, no traceback
                            distinct_field)
            distinct_field = "mac"                                                  # graceful fallback

        logging.info("Prompting for duration window")                               # before-prompt action log
        duration = duration or safe_input(                                          # caller override else prompt
            "Duration (e.g. 1d, 7d, 2w) [1d]: ",                                    # default matches API default
            context="site_wan_usage_count:duration",                                # EOF context tag
            default="1d",                                                           # explicit default for non-interactive runs
        )

        logging.info("Fetching WAN usage count for site %s distinct=%s "            # before-API-call action log
                     "duration=%s", site_id, distinct_field, duration)
        response = mistapi.api.v1.sites.wan_usages.count.countSiteWanUsage(         # actual SDK call
            self.apisession, site_id,                                               # session + path param
            distinct=distinct_field, duration=duration,                             # only the prompted query params
        )
        body = response.data or {}                                                  # normalize None to empty dict
        logging.debug("WAN usage count: total=%s results=%s limit_effective=%s",    # after-API-call summary log
                      body.get("total"), len(body.get("results") or []),
                      body.get("limit"))

        logging.info("Flattening %s result rows for site %s",                       # before-flatten action log
                     len(body.get("results") or []), site_id)
        rows = self._flatten_wan_usage_count_rows(site_id, body)                    # build list of dicts
        logging.debug("Flattened %d rows", len(rows))                               # after-flatten count log

        logging.info("Writing WAN usage counts via DataExporter")                   # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            rows,                                                                   # list-of-rows interface
            filename=f"site_{site_id[:8]}_wan_usage_counts",                        # human-friendly stem
            api_function_name="countSiteWanUsage",                                  # PK strategy lookup key
        )
```

The helper `_flatten_wan_usage_count_rows` follows the same comment and log density
rules, stays under 25 lines, and lives on the same `SiteStatsExportUtils` class --
no standalone wrapper functions. It copies the envelope fields (`distinct`, `start`,
`end`, `limit`, `total`) onto every output row, lifts the row-level grouping value
into `distinct_value`, and JSON-encodes any extra `additionalProperties` strings into
the `raw_extra_json` column.

The `--test` sweep automatically skips heavy / destructive operations (14, 18, 63-65,
90-100). Menu 91 sits inside the standard sweep range, so a green run confirms the
new item works end-to-end against the site configured in `.env`.
