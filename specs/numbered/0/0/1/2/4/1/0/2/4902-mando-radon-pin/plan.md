The pin test reads the committed pin and compares it with the radon limit.

```python
    def test_pinned_mando_stays_below_radon_limit(self) -> None:
        """Fail when the pinned mando reaches 0.8, which radon 6.0.1 rejects."""
        logging.info("action=%s phase=%s", "read_mando_pin", "before")  # Trace before the file read
        requirements = (REPOSITORY_ROOT / "requirements-dev.txt").read_text(encoding="utf-8")  # Read the committed pin set
        pin = re.search(r"^mando==([0-9][0-9.]*)$", requirements, re.MULTILINE)  # Match the exact mando pin line
        logging.debug("action=read_mando_pin phase=after found=%s", pin is not None)  # Report whether the pin exists
        assert pin is not None, "requirements-dev.txt must pin mando"  # A missing pin cannot prove the limit
        assert Version(pin.group(1)) < Version("0.8"), f"mando {pin.group(1)} conflicts with radon 6.0.1"  # Reject 0.8 and later
```
