# Data Model: Gated Converter Administration and Unassignment

This model defines the records that the administration path creates. Three record types come from issue 4636: `ApprovalRecord`, `OperationRecord`, and `BackupManifest`. The store is `PrivateStateStore` from issue 4636. This model adds the scope and the object outcome. No database table is added.

## AdministrativeScope

Natural key: `organization_id` with `family` and the sorted `object_ids` set.

| Field | Type | Rule |
| --- | --- | --- |
| `organization_id` | UUID string | Must match the organization of each backup manifest (FR-008). |
| `family` | enum | One of `gateway_templates`, `networks`, `services`, `device_profile_unassign`, or `site_template_unassign`. |
| `object_ids` | list of strings | One to 25 unique values. UUIDs for each family except `device_profile_unassign`. MAC addresses for `device_profile_unassign` (FR-005, FR-013). |
| `objects` | list of ScopeObject | One entry for each value in `object_ids`. |
| `review_status` | enum | `current` or `blocked`. A blocked review lists its reasons (FR-007). |
| `blocked_reasons` | list of strings | Plain text. Empty when `review_status` is `current`. |
| `backup_manifest_ids` | list of strings | One manifest for each family in scope (FR-008). |
| `scope_digest` | hex string | SHA-256 of the canonical JSON of the scope fields above (FR-006). |

The scope has no expiry. Each approval has an expiry (see ApprovalRecord). A change to `object_ids`, `family`, or any before-state digest produces a new `scope_digest`.

## ScopeObject

Natural key: `organization_id`, `family`, and `object_id`. For `device_profile_unassign`, the key also includes `deviceprofile_id`.

| Field | Type | Rule |
| --- | --- | --- |
| `family` | enum | Same as the scope. |
| `object_id` | string | The Mist identifier, or the MAC address for `device_profile_unassign`. |
| `deviceprofile_id` | UUID string | Present only for `device_profile_unassign`. |
| `display_name` | string | Plain text for the operator. It holds no secret. |
| `before_state_digest` | hex string | SHA-256 of the canonical JSON of the current object, read before the scope review. |
| `reference_status` | enum | `none_found`, `blocked`, or `unverified`. `unverified` blocks the review (FR-007, UV-01). |

## ApprovalRecord (from issue 4636)

Natural key: `approval_id`. The store writes one record for each approval.

| Field | Type | Rule |
| --- | --- | --- |
| `approval_id` | UUID string | Generated by the server. |
| `operator_id` | string | The identity that the verifier returned. Required (FR-003). |
| `scope_digest` | hex string | The digest that the scope confirmation echoed (FR-009). |
| `created_at_utc` | ISO 8601 UTC string | Set when the scope confirmation succeeds. |
| `expires_at_utc` | ISO 8601 UTC string | `created_at_utc` plus 15 minutes. The boundary is inclusive (FR-010). |
| `consumed_at_utc` | ISO 8601 UTC string or null | Set once when the run starts. A second use returns 409 (FR-010). |

## OperationRecord (from issue 4636)

Natural key: `operation_id`.

| Field | Type | Rule |
| --- | --- | --- |
| `operation_id` | UUID string | Generated by the server. |
| `organization_id` | UUID string | Same as the scope. |
| `family` | enum | Same as the scope. |
| `scope_digest` | hex string | The digest of the reviewed scope. |
| `approval_id` | UUID string | The approval that the run consumed. |
| `backup_manifest_ids` | list of strings | The verified manifests that the run used. |
| `phase` | enum | One of the phases in the transition table below. |
| `started_at_utc` | ISO 8601 UTC string | Set before the first write (FR-012). |
| `finished_at_utc` | ISO 8601 UTC string or null | Set when the run reaches a final phase. |
| `object_outcomes` | list of ObjectOutcome | One entry for each object in the run. |

## ObjectOutcome

Natural key: `operation_id`, `family`, and `object_id`. For `device_profile_unassign`, the key also includes `deviceprofile_id`.

| Field | Type | Rule |
| --- | --- | --- |
| `action` | enum | `unassign` or `delete`. |
| `outcome` | enum | `verified`, `failed`, `indeterminate`, or `not_attempted` (FR-016, FR-017). |
| `read_back` | enum | `absent`, `present`, `mac_unassigned`, `mac_assigned`, or `unknown`. |
| `detail` | string | ASCII text. It holds no raw response body, token, or password (FR-018). |

Each object outcome has one meaning. The outcome `refused` does not exist for an object. A gate refusal returns an HTTP status before any object outcome exists (`portal-administration.md`).

## Phase transitions for OperationRecord

| From | To | Condition |
| --- | --- | --- |
| `scope_reviewed` | `approved` | The scope confirmation matches the current scope digest and the operator is verified. |
| `approved` | `executing` | The approval is unexpired and unused. The store persisted the operation record (FR-012). |
| `approved` | `scope_reviewed` | The approval expired or the scope changed. |
| `executing` | `completed` | Each object outcome is `verified`. |
| `executing` | `stopped` | One object outcome is `failed`. Later objects are `not_attempted`. |
| `executing` | `reconcile_required` | One object outcome is `indeterminate`. Later objects are `not_attempted`. |
| `stopped` | `scope_reviewed` | The operator starts a new scope review. |
| `reconcile_required` | `scope_reviewed` | A read-back reconciles every `indeterminate` object, and the operator starts a new scope review. |

Any other transition raises `StateRefused` from the transition table in issue 4636 (`state/lifecycle/transitions.py`). These phases add edges to that table. Issue 4636 must add these edges before task T010 starts.

## BackupManifest (from issue 4636, created under issue 4643)

Natural key: `manifest_id`.

| Field | Type | Rule |
| --- | --- | --- |
| `manifest_id` | string | Generated by issue 4643. |
| `organization_id` | UUID string | Must match the scope (FR-008). |
| `family` | enum | Must match the scope family (FR-008). |
| `object_count` | integer | Must equal the number of objects in the manifest. |
| `checksum_sha256` | hex string | Must match the stored content. |
| `pagination_complete` | boolean | Must be `true` (FR-008). |
| `created_at_utc` | ISO 8601 UTC string | Set by issue 4643. |

A manifest that fails any rule blocks the run with 409 (FR-008). Open item UV-11 asks whether issue 4643 stores the complete prior state.

## Relationships

- One AdministrativeScope has one to 25 ScopeObject entries.
- One ApprovalRecord belongs to one scope digest and one operator. One OperationRecord consumes one ApprovalRecord.
- One OperationRecord has one ObjectOutcome for each object that the run attempted or skipped.
- One OperationRecord uses one or more BackupManifest records for its family.

## Persistence keys

The store writes each record as one sealed JSON file under `data/cisco_config_converter/state/` (issue 4636 decision D-3). This record uses these paths:

- `data/cisco_config_converter/state/approvals/{approval_id}.json` for each ApprovalRecord. The file name is the approval UUID.
- `data/cisco_config_converter/state/operations/{operation_id}.json` for each OperationRecord, including its object outcomes. The file name is the operation UUID.

Neither path enters the repository. The `.gitignore` file ignores `data/` (RC-52).
