# Notice contract

- `results-truncated` remains the existing notice identifier.
- A status role announces changed notice text politely.
- `results-clipped-row` opens the first clipped row through the existing row-detail behavior.
- `results-complete-output` targets the existing `outputFiles` destination.
- The sort warning remains visible when the response sets `sort_truncated`.
- Short values alone produce no notice.
- Download URLs, paging, and data response fields remain unchanged.
