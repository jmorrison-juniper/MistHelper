# Phase 1 Quickstart: getMspOrg

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ and `python-dotenv` installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_MSP_ID=<your-default-msp-uuid>   # optional default for the msp_id prompt
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout.

## Expected output filenames

Files land under `data/`. On Linux, ensure the directory is writable by the
non-root container user before first run:

```bash
chmod -R 777 data/
```

- CSV: `data/msp_<first-8-of-msp-uuid>_org_<first-8-of-org-uuid>.csv`
- SQLite: `data/mist_data.db`, table `msp_org`
- ArangoDB: collection `msp_org` (when ArangoDB backend is configured)
- Redis: key `mist:msp_org:<id>` (when Redis backend is configured)

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline-comment and action-logging coverage
can be reviewed before the code is written. Every executable line carries a
`#` comment (Constitution VI), and every meaningful action is bracketed by
`logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class MspExportUtils:                                                                # new (or existing) class, no wrapper

    def export_msp_org_details(self, msp_id=None, org_id=None):                      # menu 94 entrypoint, <=3 params
        logging.info("Prompting for msp_id for MSP org details menu item")           # before-prompt action log
        msp_id = msp_id or safe_input(                                               # honor caller override else prompt user
            "MSP ID (UUID): ",                                                       # human-readable prompt text
            context="msp_org:msp_id",                                                # SSH/container EOF context tag
            default=os.environ.get("MIST_MSP_ID", ""),                               # fall back to .env default
        )
        if not is_valid_uuid(msp_id):                                                # validate before any API call
            logging.warning("Invalid msp_id %s -- aborting menu 94", msp_id)         # log validation failure cleanly
            return                                                                   # early return per safety-first

        logging.info("Prompting for org_id for MSP org details menu item")           # before-prompt action log
        org_id = org_id or safe_input(                                               # honor caller override else prompt user
            "Org ID (UUID): ",                                                       # human-readable prompt text
            context="msp_org:org_id",                                                # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                               # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                                # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 94", org_id)         # log validation failure cleanly
            return                                                                   # early return per safety-first

        logging.info("Fetching MSP-managed org details for msp %s org %s",           # before-API-call action log
                     msp_id, org_id)                                                 # both UUIDs included for traceability
        response = mistapi.api.v1.msps.orgs.getMspOrg(                               # actual SDK call (one HTTP GET)
            self.apisession, msp_id, org_id,                                         # required path params, no query params
        )
        body = response.data or {}                                                   # normalize None to empty dict
        logging.debug(                                                               # after-API-call summary log
            "MSP org: name=%s msp_name=%s session_expiry=%s allow_mist=%s",
            body.get("name"), body.get("msp_name"),
            body.get("session_expiry"), body.get("allow_mist"),
        )

        logging.info("Flattening MSP org payload")                                   # before-flatten action log
        row = self._flatten_msp_org(body)                                            # build one summary dict
        logging.debug("Flattened 1 MSP org row")                                     # after-flatten count log

        logging.info("Writing MSP org via DataExporter")                             # before-export action log
        DataExporter.write_with_format_selection(                                    # multi-backend write
            [row],                                                                   # list-of-rows interface
            filename=f"msp_{msp_id[:8]}_org_{org_id[:8]}",                           # human-friendly stem
            api_function_name="getMspOrg",                                           # PK strategy lookup key
        )
```

The `_flatten_msp_org` helper follows the same comment- and log-density rules,
stays under 25 lines, and lives on the same class -- no standalone wrapper
function.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 94 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 94 sits inside the standard sweep range, so a green run
confirms the new item works end to end against the MSP/org pair configured in
`.env`.
