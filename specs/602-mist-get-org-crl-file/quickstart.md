# Phase 1 Quickstart: getOrgCrlFile

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new
menu item on a Windows 11 dev box. Container parity is identical (paths
normalize via `pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit
this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_ORG_ID=<your-default-org-uuid>   # optional default for the org_id prompt
```

Loading is handled by the existing `python-dotenv` bootstrap in
`MistHelper.py`. The API token is consumed by `mistapi.APISession` and is
never written to logs or stdout. The CRL bytes are likewise never logged in
full -- only length and SHA-256 fingerprint appear at DEBUG.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it
with `chmod -R 777 data/` on Linux first to satisfy the non-root container
user).

- Raw CRL blob:
  `data/org_<first-8-of-org-uuid>_crl_<YYYYMMDDTHHMMSSZ>.crl`
  Example: `data/org_0a1b2c3d_crl_20260629T225100Z.crl`
- Metadata CSV: `data/org_<first-8-of-org-uuid>_crl_metadata.csv`
  (one row appended per poll)
- SQLite: `data/mist_data.db`, table `org_crl_metadata` (composite PK on
  `(org_id, fetched_at_utc)`, see [data-model.md](./data-model.md))

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton
documents the expected shape so that inline comment and action logging
coverage can be reviewed before the code is written. Every executable line
carries a `#` comment (Constitution VI), and every meaningful action is
bracketed by `logging.info()` / `logging.debug()` calls (Constitution VII).

```python
class OrgConfigExportUtils:                                                         # existing class, no new wrapper

    def export_org_crl_file(self, org_id=None):                                     # menu 96 entrypoint
        logging.info("Prompting for org_id for CRL file menu item")                 # before-prompt action log
        org_id = org_id or safe_input(                                              # honor caller override else prompt user
            "Org ID (UUID): ",                                                      # human-readable prompt text
            context="org_crl_file:org_id",                                          # SSH/container EOF context tag
            default=os.environ.get("MIST_ORG_ID", ""),                              # fall back to .env default
        )
        if not is_valid_uuid(org_id):                                               # validate before any API call
            logging.warning("Invalid org_id %s -- aborting menu 96", org_id)        # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        logging.info("Fetching CRL file for org %s", org_id)                        # before-API-call action log
        response = mistapi.api.v1.orgs.crl.getOrgCrlFile(                           # actual SDK call
            self.apisession, org_id,                                                # only path param required
        )
        body = response.data or {}                                                  # normalize None to empty dict
        raw_b64 = body if isinstance(body, str) else body.get("data", "")           # response is documented as a bare string
        crl_bytes = base64.b64decode(raw_b64) if raw_b64 else b""                   # decode once into binary
        crl_sha256 = hashlib.sha256(crl_bytes).hexdigest()                          # fingerprint for rotation queries
        logging.debug(                                                              # after-API-call summary log (no bytes)
            "CRL fetched: length=%d sha256=%s",
            len(crl_bytes), crl_sha256,
        )

        fetched_at_utc = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")  # poll timestamp for composite PK
        blob_filename = (                                                           # deterministic sidecar filename
            f"org_{org_id[:8]}_crl_"
            f"{fetched_at_utc.replace('-', '').replace(':', '').replace('Z', 'Z')}"
            ".crl"
        )
        blob_path = os.path.join("data", blob_filename)                             # Windows-safe path joining
        logging.info("Writing raw CRL blob to %s", blob_path)                       # before-blob-write action log
        with open(blob_path, "wb") as blob_fh:                                      # binary write of decoded CRL
            blob_fh.write(crl_bytes)                                                # bytes to disk
        logging.debug("Wrote %d bytes to %s", len(crl_bytes), blob_path)            # after-blob-write summary log

        metadata_row = {                                                            # one row per poll, composite PK
            "org_id": org_id,                                                       # PK part 1
            "fetched_at_utc": fetched_at_utc,                                       # PK part 2
            "content_encoding": "base64",                                           # API-documented constant
            "crl_length_bytes": len(crl_bytes),                                     # decoded byte count
            "sha256": crl_sha256,                                                   # fingerprint
            "blob_path": blob_filename,                                             # relative to data/ for portability
            "http_status": response.status_code,                                    # audit field
        }
        logging.info("Writing CRL metadata row via DataExporter")                   # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            [metadata_row],                                                         # list-of-rows interface
            filename=f"org_{org_id[:8]}_crl_metadata",                              # human-friendly stem
            api_function_name="getOrgCrlFile",                                      # PK strategy lookup key
        )
```

The method stays under 25 lines of *logical* statements (multi-line literal
expressions count as one statement). If the filename construction grows past
five lines during implementation, it is extracted to a private helper
`_crl_blob_filename(org_id, fetched_at_utc)` on the same class -- no
standalone wrapper function.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 96 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18,
63-65, 90-100). Menu 96 sits inside the standard sweep range (Viewers
cluster 92-96), so a green run confirms the new item works end to end
against the org configured in `.env`.
