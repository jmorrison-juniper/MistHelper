# Phase 1 Quickstart: countSiteBgpStats

**Spec**: [spec.md](./spec.md)
**Plan**: [plan.md](./plan.md)
**Date**: 2026-06-29

This quickstart shows a developer how to run, exercise, and validate the new menu item
on a Windows 11 dev box. Container parity is identical (paths normalize via
`pathlib.Path` and `os.path.join`).

## Prerequisites

- Windows 11 with PowerShell 7+ (or any shell on Linux container).
- Python 3.13 or newer on PATH.
- Repository cloned at the worktree root referenced in `plan.md`.
- Working `.venv` activated:

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- `mistapi` 0.59+ installed:

  ```powershell
  python -m pip install --upgrade mistapi python-dotenv
  ```

## Required `.env` variables

Create or update `.env` in the repository root (git-ignored). Never commit this file.

```ini
MIST_HOST=api.mist.com
MIST_API_TOKEN=<your-mist-api-token>
MIST_SITE_ID=<your-default-site-uuid>   # optional default for the site_id prompt
MIST_ORG_ID=<your-default-org-uuid>     # not used by this endpoint, but loaded by the standard MistHelper bootstrap
```

Loading is handled by the existing `python-dotenv` bootstrap in `MistHelper.py`. The
API token is consumed by `mistapi.APISession` and is never written to logs or stdout.

## Expected output filenames

Files land under `data/` (the directory is enforced at runtime; create it with
`chmod -R 777 data/` on Linux first to satisfy the non-root container user).

- CSV: `data/site_<first-8-of-site-uuid>_bgp_stats_count_<distinct_field>.csv`
  - Example: `data/site_0a1b2c3d_bgp_stats_count_state.csv`
- SQLite: `data/mist_data.db`, table `site_bgp_stats_count` (all distinct groupings
  share this table; the `distinct_field` column separates them).

## Skeleton of the new method

The full implementation is generated by `/speckit.implement`; this skeleton documents
the expected shape so that inline comment and action logging coverage can be reviewed
before the code is written. Every executable line carries a `#` comment (Constitution
VI), and every meaningful action is bracketed by `logging.info()` / `logging.debug()`
calls (Constitution VII).

```python
class GatewayStatsExportUtils:                                                      # existing class, no new wrapper

    def count_site_bgp_stats(self, site_id=None, state=None, distinct=None, limit=None):  # menu 91 entrypoint
        logging.info("Prompting for site_id for BGP stats count menu item")         # before-prompt action log
        site_id = site_id or safe_input(                                            # honor caller override else prompt
            "Site ID (UUID): ",                                                     # human-readable prompt text
            context="count_site_bgp_stats:site_id",                                 # SSH/container EOF context tag
            default=os.environ.get("MIST_SITE_ID", ""),                             # fall back to .env default
        )
        if not is_valid_uuid(site_id):                                              # validate before any API call
            logging.warning("Invalid site_id %s -- aborting menu 91", site_id)      # log validation failure (no traceback)
            return                                                                  # early return per safety-first principle

        state_input = state if state is not None else safe_input(                   # ask for optional state filter
            "BGP state filter (blank for all): ",                                   # blank means no filter
            context="count_site_bgp_stats:state",                                   # EOF context tag
            default="",                                                             # default empty -> no filter
        )
        state_filter = state_input.strip() or None                                  # normalize empty -> None for SDK

        distinct_field = distinct or safe_input(                                    # ask for grouping attribute
            "Distinct attribute to count by [state | neighbor_as | vrf_name | type] (default: state): ",
            context="count_site_bgp_stats:distinct",                                # EOF context tag
            default="state",                                                        # default groups by BGP state
        ).strip() or "state"                                                        # guard against pure whitespace input

        limit_raw = limit if limit is not None else safe_input(                     # ask for row limit
            "Row limit (1-1000, default 100): ",                                    # bounded for safety
            context="count_site_bgp_stats:limit",                                   # EOF context tag
            default="100",                                                          # default matches API default
        )
        applied_limit = max(1, min(1000, int(str(limit_raw).strip() or "100")))     # clamp to safe range

        logging.info(                                                               # before-API-call action log
            "Counting BGP stats for site %s distinct=%s state_filter=%s limit=%d",
            site_id, distinct_field, state_filter, applied_limit,
        )
        response = mistapi.api.v1.sites.stats.bgp_peers.count.countSiteBgpStats(    # actual SDK call
            self.apisession, site_id,                                               # required path param
            state=state_filter, distinct=distinct_field, limit=applied_limit,       # optional query params
        )
        body = response.data or {}                                                  # normalize None to empty dict
        results = body.get("results", []) or []                                     # bucket array (may be missing)
        logging.debug(                                                              # after-API-call summary log
            "Count response: distinct=%s total=%s buckets=%d window=[%s,%s]",
            body.get("distinct"), body.get("total"), len(results),
            body.get("start"), body.get("end"),
        )

        logging.info("Flattening %d BGP count buckets for site %s", len(results), site_id)  # before-flatten log
        flat_rows = self._flatten_bgp_count_buckets(site_id, body, state_filter)    # build list-of-dicts
        logging.debug("Flattened %d rows", len(flat_rows))                          # after-flatten count log

        logging.info("Writing site BGP stats count via DataExporter")               # before-export action log
        DataExporter.write_with_format_selection(                                   # multi-backend write
            flat_rows,                                                              # list-of-rows interface
            filename=f"site_{site_id[:8]}_bgp_stats_count_{distinct_field}",        # human-friendly stem
            api_function_name="countSiteBgpStats",                                  # PK strategy lookup key
        )
```

The `_flatten_bgp_count_buckets` helper follows the same comment- and log-density rules,
stays under 25 lines, and lives on the same `GatewayStatsExportUtils` class -- no
standalone wrapper functions. It iterates `body["results"]`, extracts the single non-
`count` key out of each bucket as `distinct_value`, and emits a fully-denormalized row
matching the DDL in `data-model.md`.

## Quality gates (all must pass before commit)

Run these from the repository root with the venv active:

```powershell
python -m py_compile MistHelper.py        # 1. Syntax check (zero output = pass)
python -m ruff check MistHelper.py        # 2. Lint (zero violations = pass)
python -m black --check MistHelper.py     # 3. Format (zero diffs = pass; rerun without --check to auto-fix)
python MistHelper.py --test               # 4. Functional smoke test (menu 91 included)
```

The `--test` sweep automatically skips heavy/destructive operations (14, 18, 63-65,
90-100). Menu 91 sits inside the standard sweep range, so a green run confirms the new
item works end to end against the site configured in `.env`.
